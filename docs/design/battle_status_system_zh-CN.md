# 战斗状态与区域效果系统（Prototype 0.1）

> **历史提示（2026-11-25）**：本文描述的誓盾架势、守望壁垒、回响反击、誓约裁断与旧版裁决印记属于**守誓者 v1 技能组**。v1 已于同日被所有者确认废弃，**代码与测试全部移除**——`skill_executor.gd` 中不再有对应实现，区域效果与回响反击两个子系统也随其唯一生产者一并删除。当前生效的技能组为**守誓者 V2**（裁决印记 / 誓盾庇护 / 绝对守护 + 被动不屈誓约，见 `docs/design/OATHKEEPER_V2_DESIGN_SPEC_v1.0_zh-CN.md`）。本文其余内容描述的是状态数据结构、叠加策略与生命周期 API——这些**仍在运行**，与当前代码一致；涉及区域效果的段落仅作历史参考。

## 当前实现边界

- BattleStatusCollection 已接入 BattleController 的回合边界、单位死亡、战斗结束和新遭遇清理流程。
- 誓盾架势、回响资源、回响反击、裁决印记与破绽均已接入运行时结算。
- 守望壁垒不作为单位状态保存，而由独立的 BattleAreaEffectCollection 管理区域格子和受击时的队伍/位置判定。
- 五个 v1 主动技能均已接入第一版战斗 UI；技能按钮、目标选择和目标提示由 scripts/ui/battle_view.gd 处理。*（现状注：当前技能栏为 V2 三技 + 猎人通灵，v1 技能已从技能栏移除，机制保留用于兼容性测试。）*

## 状态数据

每个 BattleStatus 保存：
- status_id：稳定状态标识。
- source_actor_id：施加来源。
- target_actor_id：状态所属单位。
- stacks / max_stacks：当前层数和上限。
- remaining_triggers：剩余触发次数；-1 表示不限次数，0 表示已耗尽。
- expiry_boundary：到达指定阶段边界时移除；空值表示不自动到期。

## 叠加策略

| 策略 | 层数行为 | 触发次数/到期边界 |
|---|---|---|
| replace | 用新层数替换旧层数 | 完全替换为新设置 |
| refresh | 保留当前层数，并按新上限裁切 | 重置为新触发次数和新到期边界 |
| add | 当前层数加新层数，不超过上限 | 重置为新触发次数和新到期边界 |

施加非法 ID、空目标、非正层数、非法触发次数或未知叠加策略会失败且不写入状态。

## 生命周期 API

- apply_status：创建或按策略更新状态。
- has_status / get_status：查询状态。
- consume_trigger：消耗一次触发；最后一次触发后自动移除。
- expire_boundary：移除目标单位在指定阶段边界到期的状态。
- expire_all_boundary：在全体单位范围内处理指定阶段边界。
- clear_all：战斗结束或新遭遇初始化时清空全部状态。
- remove_status：按 ID 移除。
- clear_actor：清空单位全部状态。

## 已接入状态效果

### 誓盾架势（oathguard）与回响（echo）

- 誓盾架势消耗 1 AP，给瑟弗林施加一次性防御状态。
- 下一次成功承受伤害时，先按物理防御/魔法抗性结算，再将剩余伤害降低 35%，最终伤害最低为 1。
- 只有实际造成伤害后才消耗誓盾；空区域、已取消意图和零伤害不会消耗状态。
- 若该次实际命中来自已公开的敌方意图，且承伤者仍存活，则额外获得一层「回响」。
- 普通玩家攻击、脚本伤害和反击伤害不会被误判为公开敌方意图。

### 回响反击（echo_counter）

- 消耗 1 AP，预备一次反击，持续至敌方阶段结束或触发一次。
- 只有已公开的敌方意图实际命中瑟弗林时才触发。
- 基础反击伤害为攻击力的 0.8×物理伤害。
- 若攻击来源带有 judgment_mark 且瑟弗林持有一层 echo，则消耗一层回响并将反击倍率提高至 1.0×。
- 追击、待机、空区域攻击、取消意图、闪避和非公开意图伤害均不触发。
- 反击伤害不会递归触发回响反击；反击击败攻击者时，已经命中的原意图仍保持已执行状态。

### 裁决印记（judgment_mark）与破绽（exposed）

- request_judgment_mark(target_actor_id) 校验战斗阶段、目标存活/敌对、曼哈顿距离 1–4、视线（同行、同列或对角直线且路径无遮挡）和 1 AP；成功后给目标施加印记。
- 当前回合已公开的活动攻击意图会立即标记为「受裁决」，不改变目标格或区域范围。
- 单体攻击（普通近战、瞄准射击）在防御/抗性结算前将原始伤害降低 25%；攻击实际执行后消耗印记。
- 蓄力格子攻击和区域攻击不降低伤害、不改变预告范围；成功执行后消耗印记，并给攻击来源施加 exposed。
- exposed 在下一玩家阶段持续有效，使物理防御和魔法抗性各降低 200；玩家结束该回合时到期。
- 待机/追击不被标记为攻击；若本次敌方阶段没有成功执行攻击，印记会延期并保留至下一次敌方阶段结束。目标下一次生成攻击意图时会被标记；若第二个敌方阶段仍未成功执行攻击，则印记到期。被取消或未命中的攻击不会触发破绽。
- request_oath_severance(target_actor_id) 校验 1–2 格、视线（同行、同列或对角直线）、存活敌人、印记与 2 AP；确认后先消耗印记，再取消目标当前活动意图（若有），最后造成 1.4×物理伤害。
- 成功取消时意图原因记录为 oath_severance，并发出 intent_severed 事件；该敌人在本敌方阶段不会执行该意图。

## 守望壁垒（区域效果）

- 消耗 1 AP，以瑟弗林施放时所在格为中心，锁定中心及上下左右相邻格。
- 区域内同队单位受到物理与魔法伤害均降低 20%。
- 区域格子在施放时锁定；单位受击时根据其当时所在格和队伍关系动态判定，移动进出区域会改变保护结果。
- 再次施放会替换旧的同 ID 区域，不会叠加；在下一玩家回合开始时到期。
- BattleAreaEffect / BattleAreaEffectCollection 与单位状态容器分离，供未来其他区域技能复用。
