## 使用方式

- 每项任务有固定 ID，实施 PR 引用对应 ID。负责人由接手者登记。
- 完成时记录源码提交、验证结果、PR 和实际工时，再勾选任务。
- 工程估算包含实施、针对性验证、全量回归、文档与集成，每人日约六小时有效开发。
- 阶段估算按工作包计，子任务共享验证与集成时间。新增内容与设计等待时间需要重新估算。
- 任务清单供 agent 本地协作。单独设定或调整清单时留在本地，实际实施产生可验证成果后再同步 PR。
- 每次实施先 fetch 并核对最新 main 和开放 PR，从 main 新开分支。全量回归通过后开 PR，双端 CI 成功且 mergeable_state=clean 后合并，删除本轮分支。
- 断言变化同步 BASELINE 的总数与合计，以及守卫扫描的文档副本。
- 完成记录使用「ID / 负责人 / 提交 / 验证 / PR / 实际人日」格式。
