ECHO — Windows 工程验证包

这是供人工验收的试玩构建。自动化通过不表示交互、平衡或性能已验收。
运行环境：Windows 10/11 x64；无需安装 Godot 或 Python。
解压整个 ZIP 后运行 ECHO_Windows_x64.exe。不要在 ZIP 预览中直接启动。

包内文件
- ECHO_Windows_x64.exe：内嵌游戏资源的独立程序。
- manifest.json：源码提交、是否有未提交改动、引擎、模板及 exe SHA-256。
  source_dirty 必须为 false 才可作为指定提交的验收包。
- package-content.json：包内资源清单；不含测试、源图、工具和工程文档。
- logs：导入、全量回归、导出、资源检查、无界面启动的工程日志。

操作与路线
- 主菜单 → 开始游戏 → 营地 → 选择地图：教学遗迹 / 未尽之春。
- 营地可查看角色并编辑三套编队，每队最多三人；未尽之春先进入章节页，再选择探索模式。教学使用固定阵容。
- 现有角色为瑟弗林、樱和德斯特·李；章节图鉴展示目录，永久发现/解锁仍未实现。
- 营地的残片入口管理模块和推荐构筑；通讯终端为本地邮件，未读与待领奖分开统计，不是在线账号邮箱。
- 左键移动；1–4 选技能，再点合法目标；樱的落英可以点空地。
- Q/E 转视角；B 打开背包；Enter/Space 结束回合。
- 场上只一名我方角色。点击左下角色卡上方队友头像或按 Tab，我方回合花 1 AP 换人；替补头像调暗。
- 角色各自保留生命、盾、能量、状态与装备，背包共享。换人有短暂入场动画，连续点击不会重复扣费。
- 死亡角色本局退场，自动顺位补上下个存活者，不花 AP；全灭结束本局。暂停和下一场仍保留死亡名单。
- 鼠标右键取消选择；Esc 打开暂停菜单。
- 暂停可保存并返回标题，再从「继续旅程」恢复。
- 春之境普通模式选格后确认移动；困难模式先绘制以 Boss 为终点的路线。
- 部署先选格，确认后角色才显示；灰色续行按钮不应产生操作。
- 敌方攻击地块统一红色，重叠不加深；左侧背包按钮下可隐藏/显示攻击，敌人移动箭头保持原样。
- 移动范围默认隐藏：点当前角色或当前头像显示绿区，右键取消；选技能、移动完成、换人和结束回合会收起。
- 技能实际覆盖为淡黄色内部与连续浅金边；薄金轮廓表示可点选地格。红虚线为条件攻击，白箭头为敌人移动。

当前限制与待验证项
- 视角卡死尚未复现；连续旋转与敌方演出压力回归通过，仍需原设备复测。
- AP 原始“首次免费、第二次扣完”的表象未在底层复现。已修正误移动、残留选择和费用反馈，四技能逐次扣费及击杀返还已回归。
- Boss 败北特殊续行规则等待开发者裁决；现行数值、普通敌人、经济与难度仍是试玩参数。
- Windows 交互、教学理解、三模板两模式整局、目标设备性能和干净环境验收待人工完成。
- 当前内容为教学三关与春之境；后续区域、未封版角色、成长/契约/正式剧情尚未交付。Android 暂缓。
- 已知问题：生命残片跨遭遇的旧上限覆盖问题（ECHO-207）已于 2026-11-28 修复；旧档若已写死含残片加成的上限、之后又卸下模块，无法反推原比例，保持存档值。

存档与回滚
- Windows 默认存档位于 %APPDATA%\Godot\app_userdata\ECHO\。
- 更换版本前退出游戏，将整个 ECHO 存档文件夹备份到另一个目录。
- 保留上一版本 ZIP 和 manifest。回滚时退出游戏，解压上一版本至另一个程序目录。
- 较新存档可能不被旧版接受；需要恢复时使用该旧版本运行前的备份，勿与当前档混合。
- 不要直接编辑 JSON 排错；损坏档和原始日志应保留供开发者诊断。

问题反馈
请通过项目开发者或 https://github.com/qingxu443-dev/echo-game/issues 提供：
1. manifest 中 source_commit / source_dirty / sha256；
2. Windows、显卡驱动、分辨率、显示缩放；
3. 模板/模式/遭遇、角色与技能、精确操作顺序；
4. 预期与实际结果、复现次数、截图/录像；
5. 涉及 AP 时记录选中前、确认后、击杀后的余额；
6. 游戏日志及发生问题前的存档副本。
游戏日志位于上述存档目录下的 logs/godot.log；包内 logs 只记录构建验证。
完整人工验收表见仓库 docs/delivery/WINDOWS_DELIVERY.md。

战后保存回归修复
- 若旧版本停在“战后奖励存档未完成”，退出旧程序并启动本次新版，选择“继续旅程”后确认保留的结算。
- 不需新开局或删除存档；同一战果重复确认不会重复发奖。
