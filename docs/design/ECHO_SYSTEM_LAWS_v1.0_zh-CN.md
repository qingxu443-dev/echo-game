## 二、四大核心法则

### 法则一｜既定回响

> **ECHO 驱动的攻击不是随机应变，而是历史上某次挥击的「重演」。一旦回响锁定坐标与目标，落地前无法更改轨迹。**

**机制对应**

| 已实现的机制 | 法则解释 |
|---|---|
| 敌方意图在玩家回合开始时公开 | 预告不是 UI 便利，是回声的物理表现 |
| 执行时绝不 retarget、绝不重选技能 | 回声一旦发出，不可改写 |
| 目标已死 / 地形变化 / 出界导致无法执行时**取消**而非改目标 | 回声没有落点，自然消散 |
| 敌人死亡时其预告立即取消 | 发声者消失，回声终止 |

**设计价值**：确立《陷阵之志》式的**确定性解谜战棋**——玩家靠读懂意图、走位、位移、打断来破局，而不是赌闪避与暴击。

**可参数化项**

| 参数 | 默认 | 含义 |
|---|---|---|
| `telegraph_lead_turns` | 1 | 预告提前量（回合） |
| `telegraph_mutable` | false | 预告发出后是否可改写 |
| `echo_lock_mode` | actor / tile / area | 回声锁定方式 |

#### 推论：余震（Echo Residue）

> **回声不会在落点立刻消散。**

敌方攻击结算后，其落点可保留残余回响，于下一回合原样再触发一次。

- **它是法则一的直接推论，不是异象**，因此**不进入关卡异象池**。
- 零新增 UI 成本：复用现有 1 回合预警表现，只在已结算格子上叠一层「余响」标记。
- 它补上了现有战斗的一处空白：目前敌人打完即消失，法则一只有「预告」没有「回响」，名不副实。
- **落地路径**：先做成**单个敌人的专属能力**验证 1–2 个版本；升格为通用机制之前，任何关卡都不挂这个机制。

### 法则二｜三拍律动（行动经济）

> **守誓者在回声场中每一轮次仅有有限次「介入现实」的窗口。进攻、立盾、位移必须相互让渡，不存在零代价的完美行动。**

**机制对应**

| 已实现的机制 | 法则解释 |
|---|---|
| 每回合固定行动点（`player_ap`） | 本轮能兑现的誓约数量 |
| 移动消耗行动点、正交格数受限 | 靠近也是兑现——位置本身是誓约的一部分 |
| 猎人通灵的两回合冷却（**当前唯一的冷却**） | 债务清算期。四个主动技能只有 AP 成本，没有冷却 |
| 猎人通灵不占行动点 | **它不是誓约，是外部援助**，故不记账 |
| 施放后立即结算，仅在确认目标前可取消 | 誓言出口即生效，不可反悔 |

**术语纪律**：本文档统一使用「誓约 / 守誓者 / 兑现」体系。现有技能命名（裁决印记、誓盾庇护、不屈誓约、绝对守护）已全部属于誓约语义，**不引入「调律者」「调律」等第二套隐喻**。

> **核对修正（2026-11-25）**：上表原写作「技能冷却 → 债务清算期」，与实现不符。四个主动技能都没有冷却，全代码唯一的冷却是猎人通灵的两回合冷却，已按实现更正。若要靠冷却承担法则二的「让渡」，需要先给技能加冷却——那是设计变更，不是文档修订。

> ⚠️ **现状说明**：当前实现尚未达成本法则要求的「相互让渡」——行动点预算与技能成本的关系使某些回合不存在真实取舍。这属于**数值与结构问题**，由《数值与平衡专项》处理，**不在本文档内提出改动方案**。

### 法则三｜回声衰减（抗性与减伤底层模型）

> **在系统底层，抗性 = 对回声冲击的衰减系数。**

**机制对应**（数值口径见 `docs/combat_stats_zh-CN.md`）

```
透过率 = K / (K + R)
减伤率 = R / (K + R)
默认 K = 1000，R = 单位防御 / 魔法抗性
```

**叙事边界（重要）**

对外文本与视觉演出**不要**硬拗「物理护甲是在隔绝声音」。先锋举盾抗刀，直觉上依然是盾牌坚固。「回声衰减」**仅作底层策划口径与关卡异象解释使用**，避免玩家认知割裂。

**设计价值**：抗性不再是一组凭空的数字，而是可被关卡统一调控的单一参数 `K`。

---

### 法则四｜局部异象（关卡参数变异）

> **异象不是「奇怪的现象」，是 ECHO 法则在局部失效或加倍。**

**机制对应**：通过关卡配置覆写少量全局参数，低成本制造区域差异与配队变化。

> **实现状态（2026-11-25 核对）**：本节的参数覆写机制**尚未实现**。`K` 目前是 `CombatMath.calculate_damage` 公式内的字面量，既不是命名常量，也没有导出字段或关卡级入口。下表的三档数值是推演结果，不是可运行配置——要落地，先让 `K` 成为可注入参数。

#### 4.1 K 值异象表（以先锋 R = 700 为例，已核算）

| 异象 | 参数 | 先锋透过率 | 先锋减伤 | 配队导向 |
|---|---|---:|---:|---|
| 常态 | K = 1000 | 58.8% | 41.2% | 标准攻防基准线 |
| **锐化**（高穿） | K = 1500 | **68.2%** | **31.8%** | 抗性贬值，鼓励爆发速杀 |
| **钝化**（厚重） | K = 700 | **50.0%** | **50.0%** | 抗性升值，鼓励防守反击 |

> 复算：`700/1700 = 41.2%`、`700/2200 = 31.8%`、`700/1400 = 50.0%`。
> 方向：**K 越大，抗性越不值钱。**

#### 4.2 异象选型结论

**不采用「迟响」**（`telegraph_lead_turns: 1 → 2`），理由三条：

1. **UI 成本高**：表现层需同时区分「下回合生效」与「下下回合生效」两档预警。
2. **易沦为福利关**：敌人提前两回合锁死落点，玩家拥有整两回合走位窗口，实战大概率变成敌人全程打空气。
3. **稀释法则一**：预告提前太多，就从「解谜条件」退化为「背景噪音」。

**本版结论：法则一暂不新增任何全局异象。** 与法则一相关的体验改动，一律走「余震」的单怪专属能力路径验证，不占用关卡异象槽位。

## 五、实现状态对照（2026-11-25 核对）

本文档的立文原则是「每一条世界规则都必须能对应到一处已实现的机制，否则不写」。下表逐条核对这句话是否成立，避免把**设计意图**读成**已实现机制**。

| 法则 | 声称的机制对应 | 实际状态 | 核对依据 |
|---|---|---|---|
| 一 既定回响 | 预告公开、执行不 retarget、无法执行即取消、死亡即取消 | **已实现** | 意图为单向状态机（active → resolved / canceled）；各执行分支以「取消 + 原因」收尾，不重选目标；击杀时同源意图一并取消 |
| 一 推论 余震 | 落点保留、下回合原样再触发 | **未实现** | 本文档已标为待验证路径，当前代码无残余回响机制 |
| 一 可参数化项 | `telegraph_lead_turns` / `telegraph_mutable` / `echo_lock_mode` | **未参数化** | 三项均为硬编码行为，无导出字段、无配置入口 |
| 二 三拍律动 | 行动点、移动耗点、技能冷却、通灵免行动点 | **部分实现** | 行动点、移动耗点、通灵免点均已实现；**「技能冷却」不成立**——四个主动技能都没有冷却，全代码唯一的冷却是猎人通灵的两回合冷却 |
| 二 相互让渡 | 回合内存在真实取舍 | **未达成** | 本文档已自述，归《数值与平衡专项》 |
| 三 回声衰减 | `透过率 = K / (K + R)`，`K = 1000` | **已实现，但未参数化** | `CombatMath.calculate_damage` 的计算式与本文一致；但 `1000` 是公式内的**字面量**，不是命名常量，无法从外部覆写 |
| 四 局部异象 | 关卡覆写全局参数 `K` | **未实现** | 无 `K` 参数、无关卡级参数覆写机制。§4.1 的三档数值目前只是纸面推演，改动它需要先让 `K` 成为可注入参数 |

**结论**：法则一与法则三的机制对应成立；法则二的「冷却」一项与实现不符，需改写或删除；法则四整体尚无实现载体，属规划而非现状。
