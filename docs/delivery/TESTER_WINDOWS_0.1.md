# ECHO Prototype 0.1 — Windows 10/11 首次运行说明

本说明供协助测试的朋友使用。目标仅为首次导入、启动和观察原型，不要求修改代码或访问 GitHub。

当前版本还包含营地角色总览、三套最多三人的编队，以及春之境章节/图鉴页。请复测选队出征、单人部署、1 AP 头像切换、各自受伤状态继承、死亡永久退场/自动接替、暂停恢复原阵容；教学仍固定使用瑟弗林。章节图鉴为目录展示，永久发现/解锁与正式成长尚未实现。

## 交付包内容

优先使用开发者通过构建工具生成的 `ECHO_Windows_x64.zip`：解压后直接运行 exe，无需安装 Godot。包内 README、manifest、资源清单和日志分别提供操作、源码提交/校验值与工程验证证据；`source_dirty` 应为 false。请按 [Windows 交接与验收表](WINDOWS_DELIVERY.md) 记录真人操作结果。

若拿到的是源码 ZIP，则按下文导入流程操作。项目根目录必须能看到 `project.godot`。

源码运行需另行准备 Godot 4.7.2 Standard（标准版）Windows x86_64 发行包。不要使用 .NET 版；本次只做桌面运行，Android 按用户指令暂缓。

## 运行前

- 操作系统：Windows 10 或 Windows 11，64 位。
- 解压 ECHO 项目 ZIP 到一个普通文件夹，例如桌面\ECHO_Prototype_0.1。
- 从 Godot 官方下载页取得 Godot 4.7.2 Standard Windows x86_64 版本：https://godotengine.org/download/windows/
- 解压 Godot 压缩包，运行其中的 Godot 可执行文件。Godot 通常无需传统安装程序。

## 导入并启动

1. 打开 Godot。
2. 在项目管理器选择 Import（导入）。
3. 浏览并选择 ECHO 项目根目录里的 `project.godot`。
4. 导入完成后打开项目。
5. 按 F5 或点击右上角运行项目按钮，运行主项目。
6. 如果出现“选择主场景”的提示，先停止操作并截图反馈，不要自行更改项目设置。

## 本次观察项目

在主菜单进入营地大厅，选择地图后可分别验收下列两条路线。若拿到 Windows 试玩包，直接运行 ECHO 可执行文件。

### 教学遗迹

- 是否成功导入项目并进入新主菜单（含黄昏背景、飘浮光尘与悬停按钮）。
- 是否正常进入 2.5D 等距 8×8 战台，主角瑟弗林、三类敌人立绘、遗迹宝箱与 3D 障碍显示清晰。
- 按 `Q / E` 或点击左上角视角按钮旋转四对角机位时，棋盘、立绘朝向、预告区域与鼠标点选是否准确对应。
- 左下角主角头像/血条/护盾/3 AP/能量、底部 4 技能条（悬停说明）、右上角敌方行动顺序与技能充能条是否可读。
- 实操移动、施放 `[1] 誓刃`（击退并平移敌方预告）、`[2] 裁决印记`（易伤）、`[3] 誓盾庇护`（瞬发护盾）、`[4] 绝对裁决`（4 能量周围击退）及结束回合的分步敌方演出。
- 验证遗迹宝箱机制（敌人拆箱变强、击败后掉落武器/防具到地面可拾取、通关自动开完好宝箱）及按 `[B]` 打开背包穿戴/卸下/使用道具。
- 走通三关结算、下一关与战败重开（确认重开新局后装备与背包已清空）。

### 春之境

- 普通模式选择地图格、确认体力消耗并进入地点。困难模式拖动连线路径，松手时须以首领格收尾。
- 验证只部署一人，角色框上方点击队友花 1 AP 切换；替补调暗、死亡头像不可选，当前角色死亡自动顺位补人，全灭结束本局。
- 换人保留各自生命、护盾、能量与状态；装备属于当前角色，背包共享。换人动画中保存并恢复，再进下一场确认死亡者仍不可用。
- 验证敌人预告、结界节点与战后返回；精英奖励窗口退出恢复仍保留原选择。旧档既有续行待决按旧流程保留，新战斗不复活本局退场者。
- 在已有春之境存档时购买工坊补给，再进入普通档继续探索。返回大厅后确认补给仍在工坊行囊。

## 测试状态说明

暂停档类型或编码损坏时，标题页应说明无法恢复及原文件已保留，避免把受伤状态静默恢复成满血。请保留原档与日志，使用正常存档验证损血、已花 AP、选中状态及动画仍能继续；不要直接编辑自己的唯一存档来做损坏验证。

Godot 4.7.2 的 Windows 与 Ubuntu 自动化验证入口见 [工程基线](../engineering/quality/BASELINE.md)。Windows 人工验收须单独记录。

本文档面向 **Windows 桌面端人工确认**——headless 无法覆盖交互手感、画面观感与设备表现。因此仍不得将“成功导入”当作人工验收完成；需要逐一记录实际操作中的观察结果。


## 本批实机缺陷复验

逐项原因与自动化覆盖见 [实机修复记录](../engineering/quality/PLAYTEST_FIXES_2026-11-27.md)。请额外观察：

1. 受伤后反复穿脱加生命装备，卸下时应回收当前生命加成，不能逐轮刷满。
2. 连续点击左右机位，在玩家和敌方阶段均确认画面及回合继续推进；若卡死，记录遭遇与操作顺序。
3. 红/紫/蓝重叠时每格保持一个主边框，其他攻击类型保留短角标；悬停后显示对应瞄准线，其他危险格仍可读。安全格绿边、危险格小绿点均表示可移动，金角表示技能选区；施法成功/取消后恢复移动提示。角色脚下承伤不应因聚焦另一敌人而少算，范围边缘格悬停应显示该格伤害。
4. 樱在部署阶段只显示选位标记，确认后于所选格出现。
5. 落英可点空地，金角预览与实际攻击范围一致；打空也消耗目录标注的 AP。
7. 补给不足的灰色续行按钮不可误触结束探索，「结束本局」仍可主动选择。
8. 樱四技能分别观察选中、确认命中、击杀返还及 AP 不足的反馈与余额。

本轮追加：多人队伍切换后穿脱装备应只改领队，道具仍对当前角色；地图休息/治疗藏品/遗物的生命与上限应带入下场战斗。沙漏产生的临时 AP 可保存退出再恢复，换回合归基础值。请在备份后测试“暂停旧战斗→开另一局→恢复旧战斗→结算”，核对返回的是旧战斗自己的地图/资源；结算页面无法打开时应有提示且重试不重复领奖。工程故障注入不要求测试者修改唯一原档。

残片追加：同场穿脱装备及暂停恢复后再穿戴，残片百分比应保留，面板显示实际值。**已知未修**：在已有春之境队伍进入下一战前更换生命残片，旧生命上限快照可能覆盖新加成（ECHO-207）。请记录实际值；不要把这项误记为已验收通过。
