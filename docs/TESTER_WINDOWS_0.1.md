# ECHO Prototype 0.1 — Windows 10/11 首次运行说明

本说明供协助测试的朋友使用。目标仅为首次导入、启动和观察原型，不要求修改代码或访问 GitHub。

## 交付包内容

项目所有者应从 ECHO 私有仓库的 `main` 分支下载 ZIP，并将解压后的项目文件夹重新压缩或直接交付。项目根目录必须能看到 `project.godot`。

另行准备 Godot 4.x Standard（标准版）Windows x86_64 发行包。不要使用 .NET 版；本次只做桌面运行，不需要 Android 导出模板。

## 运行前

- 操作系统：Windows 10 或 Windows 11，64 位。
- 解压 ECHO 项目 ZIP 到一个普通文件夹，例如桌面\ECHO_Prototype_0.1。
- 从 Godot 官方下载页取得 Godot 4.x Standard Windows x86_64 版本：https://godotengine.org/download/windows/
- 解压 Godot 压缩包，运行其中的 Godot 可执行文件。Godot 通常无需传统安装程序。

## 导入并启动

1. 打开 Godot。
2. 在项目管理器选择 Import（导入）。
3. 浏览并选择 ECHO 项目根目录里的 `project.godot`。
4. 导入完成后打开项目。
5. 按 F5 或点击右上角运行项目按钮，运行主项目。
6. 如果出现“选择主场景”的提示，先停止操作并截图反馈，不要自行更改项目设置。

## 本次观察项目

- 是否成功导入项目。
- 是否能启动主场景。
- 是否显示 8×8 战场、主角和三种敌人。
- 是否显示 AP、生命值、敌人预兆和行动顺序。
- 点击可达格、相邻敌人和结束回合按钮时是否有响应。

## 遇到问题时

请提供：
- 游戏窗口截图；
- Godot 底部 Output（输出）和 Debugger（调试器）中红色错误的截图；
- 第一条错误文字（如果方便复制）；
- Windows 版本，以及 Godot 的完整版本号。

如果项目无法导入或启动，请停止，不要修改、删除或重命名项目文件。
