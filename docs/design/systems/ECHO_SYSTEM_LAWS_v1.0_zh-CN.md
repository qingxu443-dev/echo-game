# ECHO｜系统法则 v1.1（设计基线草案）

- **文档状态**：Draft，待评审后升为 Confirmed
- **适用版本**：ECHO Prototype 0.1 及以后
- **性质**：**机制层规范**——只陈述世界规则及其对实现的约束，不含实现状态、不含具体数值
- **基线**：不绑定任何 commit。本文档不随代码版本变化。

> **v1.1 相对 v1.0 的改动**：把三条纪律掰正。
> 1. **删去**「每一条世界规则都必须能对应到一处已实现的机制」——那句话把本文档写成了代码的镜像，导致代码一动文档就欠账。
> 2. **删去** §5「实现状态对照」——那不是世界规则，是工程快照，已迁至《实现欠账清单》。
> 3. **法则内不再出现可调数值**——行动点数、衰减常数、预告提前量一律降级为「参数」，具体取值只存在于数值主规格 / `BASELINE` / 关卡 `.tres`。

## 一、文档定位与分工

### 1.1 立文原则

> **每一条世界规则都必须指出它对实现的约束。当实现与法则冲突时，以法则为准，实现记为欠账。**

本文档不描述代码长什么样。代码改了本文档不必改；只有**法则被违反**时，才需要改代码——或者，在欠账清单上记一笔。

判别方法只有一句：**代码变了，谁该改？** 若答案是"文档"，说明文档写错了层。

### 1.2 三份文档的分工

| 文档 | 只能产出 | 不能产出 |
|---|---|---|
| 《世界观介绍 1.0》《序章》 | 氛围词表、美术参考、宣传语 | **任何世界规则**、任何机制解释 |
| **本文档** | 世界法则、机制的含义、参数**名称**与**取值范围** | 具体参数值、实现状态、进度、差距 |
| 《实现欠账清单》 | 法则与实现的差距、修法、状态 | 任何世界规则 |

**冲突时以本文档为准。** 若 1.0 某句表述与本文档法则冲突，1.0 那句作废，无需修订 1.0。

### 1.3 数值纪律

> **法则陈述关系，参数承载数值。**

- 任何会被平衡调整改变的数字，**不得**写进法则正文。
- 法则只声明参数的**存在、语义与合法范围**；默认值与当前值属于数值文档。
- 例：法则二不说「每回合 3 点」或「全队共享 5 点」，只说「每轮次有有限个介入窗口，数量由预算参数决定」。

这条纪律的目的很直接：**行动点从 3 改成 5 时，法则一个字都不用动。**

## 二、四大核心法则

### 法则一｜既定回响

> **回声先于挥击。** ECHO 驱动的攻击不是随机应变，而是历史上某次挥击的重演。回响一旦锁定坐标与目标，在落地前不可更改轨迹。

**机制对应**

| 机制 | 法则解释 |
|---|---|
| 敌方意图在玩家回合开始时公开 | 预告不是界面便利，是回声的物理表现 |
| 执行时不重选目标、不重选技能 | 回声一旦发出，不可改写 |
| 目标已死 / 地形变化 / 出界导致无法执行时**取消**，而非改指 | 回声没有落点，自然消散 |
| 敌人死亡时其未执行的意图立即取消 | 发声者消失，回声终止 |

**设计价值**：确立**确定性策略战棋**基调——玩家靠读懂意图、走位、位移、打断来破局，而非赌命中与暴击。

**参数**

| 参数 | 语义 | 合法范围 |
|---|---|---|
| `telegraph_lead_turns` | 回响提前于执行的回合数 | ≥ 1 的整数 |
| `telegraph_mutable` | 回响发出后是否可被改写 | 布尔；设计意图为否 |
| `echo_lock_mode` | 回响锁定对象：角色 / 格子 / 区域 | 三选一 |

#### 推论：余震（Echo Residue）

> **回声不会在落点立刻消散。**

攻击结算后，其落点可保留残余回响，于之后的回合再次触发。

- 它是法则一的直接推论，**不是异象**，因此不进入关卡异象体系。
- 它补上了现有战斗的一处空白：若敌人打完即消失，法则一便只有「预告」没有「回响」，名不副实。
- **落地路径**：先作为单个单位的专属能力验证；升格为通用机制之前，任何关卡都不挂这个机制。

**参数**

| 参数 | 语义 | 合法范围 |
|---|---|---|
| `residue_lifetime_turns` | 余响在落点滞留的回合数 | ≥ 1 的整数 |
| `residue_repeat_ratio` | 再触发时的效能比例 | 0 < r ≤ 1 |

### 法则二｜让渡律动

> **每一次介入现实，都必须从别处让渡。**
>
> 角色在一轮次中拥有**有限个**介入窗口。进攻、防御、位移、观察共享同一份预算，不存在零代价的完美行动。

**名词说明**：本法则旧名「三拍律动」，因绑定行动点数量而随参数变更失效。**行动点数是本法则的参数，不是本法则的内容。**

**机制对应**

| 机制 | 法则解释 |
|---|---|
| 行动点预算（玩家或队伍共享） | 本轮次可兑现的誓约数量 |
| 移动消耗行动点、正交格数受限 | 靠近也是兑现——位置本身是誓约的一部分 |
| 行动点不足时不可透支、剩余作废 | 预算不结转，每次兑现都必须是当场付清 |
| 目标确认前可取消，执行后不可撤销 | 誓言出口即生效 |

**代价的两种形式**（法则允许两种，不规定必须用哪种）

| 形式 | 语义 | 对应参数 |
|---|---|---|
| **即时支付** | 行动时直接扣减预算 | `action_cost` |
| **延后清算** | 行动后进入清算期，期间不可再次兑现 | `settlement_turns` |

两者可并存，也可只用其一。**哪一种被使用、比例如何，属于数值与实现范畴，不在本法则内规定。**

**外部援助的例外**

不属于角色自身誓约的行为（例如外部支援系统），可以不记账。判定标准是**力量来源是否属于该角色的誓约**，而不是「是否好用」。

**参数**

| 参数 | 语义 | 合法范围 |
|---|---|---|
| `ap_pool` | 一轮次的介入窗口数 | ≥ 1 的整数 |
| `ap_pool_scope` | 预算归属：单角色 / 队伍共享 | 二选一 |
| `move_cost` / `move_max_cells` | 位移代价与单次距离 | ≥ 0 / ≥ 1 |
| `action_cost` | 单个行动的即时代价 | ≥ 0 的整数 |
| `settlement_turns` | 延后清算的期数 | ≥ 0 的整数 |
| `external_aid_free` | 外部援助是否免记账 | 布尔 |

### 法则三｜回声衰减

> **伤害不是"打进去"，是"回声穿透身体"。抗性不是皮厚，是回声传不进去。**

**机制对应**

```
原始伤害 = round(攻击力 × 技能倍率)
透过率   = K / (K + R)
最终伤害 = floor(原始伤害 × 透过率)
```

`R` 为单位对应抗性，`K` 为衰减常数。**同一个抗性有三种等价的输入方式**：

| 已知量 | 换算 | 说明 |
|---|---|---|
| 整数抗性 | 直接代入 `R` | 现有单位制采用这种方式 |
| 百分比**减伤** `p` | `R = K × p ÷ (1 − p)` | `p` 是「少受多少」 |
| 百分比**透过** `t` | `R = K × (1 − t) ÷ t` | `t` 是「还要承受多少」 |

`p` 与 `t` 满足 `t = 1 − p`，两条路径必得同一个 `R`。**方向不能写反**：`p → R` 用 `p/(1−p)`，`t → R` 用 `(1−t)/t`。若把减伤率误当透过率代入，`R` 会偏离一个数量级。

**叙事边界**

对外文本与视觉演出**不要**硬拗「物理护甲是在隔绝声音」。举盾抗刀，直觉上依然是盾牌坚固。「回声衰减」**仅作底层策划口径与关卡异象解释使用**，避免玩家认知割裂。

**参数**

| 参数 | 语义 | 合法范围 |
|---|---|---|
| `attenuation_k` | 衰减常数，抗性的"汇率" | > 0；默认值见数值文档 |
| `resistance_mode` | 抗性的表达方式：整数抗性 / 百分比减伤 / 百分比透过 | 三选一 |

> K 越大，抗性越不值钱；K 越小，抗性越值钱。**K 是关卡异象的天然旋钮**（见法则四）。

### 法则四｜局部异象

> **异象不是"奇怪的现象"，是 ECHO 法则在局部失效或加倍。**

**机制对应**：异象通过覆写**已命名的法则参数**实现，而不是在代码里另开分支。

| 异象作用的法则 | 可覆写的参数 |
|---|---|
| 法则一 | `telegraph_lead_turns` / `telegraph_mutable` / `echo_lock_mode` |
| 法则二 | `ap_pool` / `action_cost` / `settlement_turns` |
| 法则三 | `attenuation_k` |

**明确不进入覆写范围的参数**

| 参数 | 理由 |
|---|---|
| `resistance_mode` | 它是抗性的**表达方式**（填表格式），不是局内规则。覆写它不产生任何玩法变化，属过度参数化 |
| `residue_lifetime_turns` / `residue_repeat_ratio` | 余震**尚未升格**为通用机制。按法则一推论，升格前任何关卡都不挂它；**升格之后**其参数才可进入覆写范围 |

**设计价值**：世界观因此成为**关卡参数的来源**，而不是装饰。异象不是"加一组数值"，是"改一条法则的表达方式"。

**参数**

| 参数 | 语义 | 合法范围 |
|---|---|---|
| `anomaly_id` | 该关所挂的异象 | 指向异象表 |
| `anomaly_overrides` | 覆写的参数集合 | 键必须是上表已有的参数名 |

> **示例**（仅说明方向，不代表当前基线）：以 `attenuation_k` 为旋钮，K 取基准值时减伤居中；K 取较大值时抗性贬值、鼓励速杀；K 取较小时抗性升值、鼓励防守反击。
> 具体取值属于数值文档，**本文档不写**。
