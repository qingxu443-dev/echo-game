# ECHO 视觉美术规范 1.1
**ECHO — Visual Art Direction Standard**

- 版本：1.1
- 适用范围：ECHO 全项目；Prototype 0.1 起作为美术方向参考
- 基准视觉：暗色奇幻、半写实幻想插画、电影感战术界面
- 规范性质：视觉方向与资产制作标准，不代表其中描述的美术资产或 UI 已全部在游戏中实现

---

## 0. 核心定义

ECHO 的视觉体系以古老、衰败、庄严而仍然遵循秩序的幻想世界为基础。

**核心原则：世界可以衰败，但秩序不能消失。**

**色彩原则：低饱和度构建世界，高饱和度定义异质性。**

**统一原则：ECHO 统一的是视觉语言，而不是所有物体的颜色。**

整体采用暗色奇幻、半写实幻想插画与克制的电影感表现。材质、光影、造型和信息层级保持统一；角色、文明、魔法和特殊区域可以拥有鲜明且彼此不同的色彩身份。

关键词：古老、庄严、克制、神秘、冷峻、秩序、余烬。

## 1. 色彩体系

### 1.1 世界基础色
用于常规环境、建筑、地形和大部分 UI：
- 煤灰、深石墨、近黑色
- 冷灰、灰蓝、石板灰
- 暗褐、灰棕、旧金属色
- 月白、银白、低亮度淡金

### 1.2 身份识别色
用于区分角色、阵营、职业、文明和魔法体系。可根据具体设定自由扩展，例如：
- 冷蓝：友方识别、秩序、守护
- 暗红：敌方识别、危险、侵略
- 翡翠绿：生命、自然、古老魔法
- 紫晶色：禁忌、未知、超自然
- 暖金：神圣、古老文明、权威

战斗中的功能色必须优先保证可读性；世界观色彩不应与战术提示产生歧义。

### 1.3 高饱和度强调色
允许角色、场景、魔法和剧情元素使用鲜艳、高饱和度颜色。高饱和度不是风格违规，而是用于建立视觉焦点和身份差异。

使用规则：
1. 鲜艳颜色应有角色、阵营、文化、魔法或剧情依据。
2. 可以用于角色主体配色，也可以用于特殊场景的大面积主题色。
3. 普通场景优先采用局部强调；特殊文明、异化区域、魔法空间和关键剧情场景可以突破常规比例。
4. 避免所有区域同时争夺视觉焦点。
5. 高饱和度元素仍须遵循统一的材质、光照、造型和画面质感。

### 1.4 色彩验收
- 颜色是否承担明确的叙事、身份或功能？
- 视觉焦点是否清楚？
- 是否影响战术信息辨识？
- 是否与角色材质和场景光照协调？
- 是否避免无意义的霓虹色堆叠？

## 2. 角色设计

角色采用半写实幻想插画风格，具备可信的盔甲结构、服装层次和材质表现。避免过度卡通化、夸张比例、无意义装饰和只靠颜色区分角色。

### 2.1 轮廓语言
角色必须在战场缩小显示时仍可辨认：
- 重要角色拥有独特外轮廓。
- 头盔、武器、肩甲、披风、翼、角等可成为识别标志。
- 职业通过体态、装备比例和姿势区分。
- 重要角色应通过纯色剪影测试：去除颜色和细节后，仍尽可能能够辨认身份。

### 2.2 色彩与个性
不要求所有角色采用黑灰色系。允许鲜红礼装、翠绿羽翼、纯白长袍、紫色晶体等鲜明设计。统一性来自造型语言、材质、光影和世界观逻辑，而非统一配色。

### 2.3 瑟弗林固定视觉特征
- 完全封闭式头盔，不露出面容。
- 窄缝式观察孔。
- 暗灰色、中等长度、末端自然破损的披风。
- 盔甲以银灰和深灰为主。
- 古老纹章与装饰保持克制。
- 整体气质沉稳、坚毅、庄严，具有守护者与裁决者的感觉。

### 2.4 角色视觉档案
重要角色应建立可复用档案，至少包括：
- 正面、侧面、背面视图
- 头部、盔甲、服装、武器和披风细节
- 主色、辅助色、强调色
- 材质说明与特殊标志
- 常态、移动、攻击、防御、受击等动作参考
- 升级、换装或剧情变化后的连续性说明

## 3. 场景与环境设计

### 3.1 主题与建筑
优先考虑古老文明遗迹、废弃神殿、石制建筑、残破城堡、地下圣堂及其他具有历史层次的幻想空间。

### 3.2 常用材质与环境元素
- 磨损石板、破裂石柱、古老雕刻
- 残破旗帜、暗色金属、枯萎植被
- 稀疏火焰、尘埃、雾气和局部魔法光源

场景装饰不得遮挡战术网格、角色轮廓和关键交互信息。

### 3.3 场景色彩
常规场景以低饱和度环境色为基础，但允许局部或整体高饱和度主题：
- 彩绘圣堂：彩色玻璃成为空间焦点
- 异化森林：鲜艳植物或发光生命体体现异常生态
- 腐化遗迹：红色或紫色侵蚀作为危险主题
- 失落圣域：金色与暖光表现神圣或古老文明

特殊场景可以大幅突破基础色彩，但必须有明确的世界观依据和视觉重心。

## 4. 战场、网格与镜头

### 4.1 视角与空间
优先采用轻度俯视、等距或接近等距的战棋视角。保证战场空间完整、单位位置容易判断、网格边界清晰、障碍物具有空间厚度。

### 4.2 网格反馈
- 默认网格：低对比度灰色线条
- 友方移动范围：半透明冷蓝色
- 选中格：更明亮的蓝白色边框
- 敌方危险区域：暗红色
- 技能范围：明确区分中心格与覆盖格

网格必须服务于战术判断，不应成为主要装饰。

### 4.3 三类构图
- 战斗构图：优先展示战场、单位关系和战术信息。
- 角色展示构图：优先表现角色轮廓、装备和性格。
- 宣传插画构图：允许更大胆的镜头、光影和情绪表达。

宣传插画的构图不能未经调整直接搬入战斗界面。

## 5. 材质与光照

### 5.1 材质语言
不同物体必须拥有可区分的质感：
- 钢铁：冷硬、细微磨损、局部反光
- 黄金：温暖、克制的金属反射
- 石材：粗糙、风化、裂纹
- 布料：柔软、自然褶皱和垂坠
- 皮革：哑光、磨损、缝线
- 水晶：半透明、折射、内部或局部发光
- 骨骼：干燥、粗糙、自然色差

避免所有材质呈现相同的塑料感或金属感。

### 5.2 光照性格
不同区域可以拥有不同光照情绪：
- 普通遗迹：冷灰色环境光
- 神圣区域：暖金色主光
- 魔法区域：具有明确色彩倾向的局部光源
- 腐化区域：暗红色或紫色环境反射
- 地下区域：局部光源与大面积阴影

光照可以改变场景情绪，但不能破坏角色和战术信息的可读性。角色轮廓必须能够从环境中辨认；远景可适当降低对比度以增强纵深。

## 6. 战斗 UI 与 HUD

UI 采用古典幻想风格与现代信息排版相结合的方式，像一套属于古老文明的战术仪表系统，而不是现代科技操作面板。

### 6.1 面板与装饰
- 深灰色半透明面板
- 细金属边框、低亮度分隔线
- 少量古典纹章和几何角饰
- 适度层次阴影
- 避免大量复杂花纹、过度圆角和现代玻璃拟态

### 6.2 排版
- 信息层级清晰，标题与正文明确区分
- 数值信息紧凑、易读
- 技能名称与图标一一对应
- 中文字体优先选择易读、具有古典气质的风格
- 小尺寸信息必须保证可读性

### 6.3 战斗 HUD 建议布局
- 左下角角色信息：立绘、名称、等级、生命值、行动点数
- 底部中央技能栏：图标、快捷键、技能名称、可用状态
- 右上角敌方意图：行动图标、行动名称、目标或距离信息
- 右下角回合操作：具有古典金属边框的重要操作按钮

角色立绘需要有视觉存在感，但不得遮挡重要战场区域。

### 6.4 UI 颜色
面板保持暗色基底；银白、淡金用于重点和边框；蓝红等功能色用于战术识别。高饱和度装饰色不得削弱文本、数值和操作状态的辨识度。

## 7. 图标与技能视觉语言

技能图标采用统一的**精细线描 × 古典纹章 × 银金属质感**：
- 图形结构清楚，轮廓可辨
- 线条粗细与视觉密度统一
- 背景低干扰
- 避免卡通贴纸和现代办公软件图标风格

不同技能可以拥有不同符号和功能色，但应属于同一套图标体系。

## 8. 动画与动作语言

动画强调重量、方向、节奏和接触反馈，不追求无差别的夸张表现：
- 重甲角色：沉稳、有重量感
- 轻型角色：迅速、灵活
- 防御动作：稳定、承受冲击
- 攻击动作：明确力量方向和接触点
- 施法动作：蓄力、释放、结束三个阶段

瑟弗林的动作应沉稳、坚定，不应表现为轻巧敏捷的刺客风格。

## 9. 技能特效与战斗反馈

特效采用低饱和度、局部集中、具有材质感的表现方式。允许特殊技能使用鲜明颜色，但不能遮挡角色、网格和战术信息。

瑟弗林五技能的建议视觉语言：
- 誓盾架势：银白色环形护盾，短暂收束
- 守望壁垒：蓝色几何屏障，地面十字纹章
- 裁决印记：暗红色印记，清晰中心符号
- 回响反击：银蓝色瞬间爆发，明确反击轨迹
- 誓约裁断：金白色裁决符号，短暂压制感

其他技能应建立自己的形状、颜色、运动方式和反馈节奏，不能只靠换颜色区分。

## 10. UI 动效与交互反馈

UI 可以具有生命力，但动效必须克制、快速且有明确反馈目的：
- 选中角色时，信息面板平滑切换
- 技能可用时，图标可出现微弱呼吸光
- AP 消耗时，行动点标识逐个熄灭
- 生命值变化时，血条平滑更新
- 回合切换时，敌方意图面板依次高亮
- 技能确认时，提供简短、明确的反馈

避免所有按钮持续发光、晃动或播放无意义动画。

## 11. 视觉连续性与资产管理

重要角色、场景、UI、图标和特效都应有可追溯的视觉参考。

资产更新时：
- 保留角色核心识别特征
- 保持同一材质的表现逻辑
- 保持 UI 图标、边框和字体体系一致
- 记录色彩、比例、视角和关键细节
- 不得因单张新图好看而破坏既有设计连续性

同一角色在立绘、战场模型、头像和宣传图中可以因媒介而调整细节，但身份特征必须一致。

## 12. 跨场景统一原则

场景与 UI 必须属于同一个世界：
- 石材环境与暗色金属 UI 相协调
- 真实盔甲与古典纹章图标相协调
- 环境光与 UI 高亮色相协调
- 战术蓝红色与世界观色彩体系相协调

避免卡通角色搭配写实战场、霓虹科技 UI 搭配古代遗迹、鲜艳贴纸图标搭配暗色金属面板、现代玻璃拟态面板搭配古典纹章等无设计依据的混搭。

**统一的是视觉语言，不是所有角色、文明和区域的外观。**

## 13. 质量验收清单

每项美术资产交付前检查：
1. 是否符合 ECHO 的世界观和视觉语言？
2. 角色轮廓是否清晰、可辨认？
3. 材质是否有可信且可区分的表现？
4. 色彩是否具有明确身份或功能？
5. 高饱和度元素是否有合理依据和视觉重心？
6. 光照是否服务于空间与情绪？
7. 战术信息是否清晰，没有被装饰或特效遮挡？
8. 是否与已有角色、场景、UI 保持连续性？
9. 是否适应游戏实际镜头和目标分辨率？
10. 是否避免无意义的复杂度和视觉噪声？

如果设计虽然漂亮，却破坏整体统一性或战术辨识度，应优先调整设计。

## 最终美术方向定义

ECHO 不是一款所有东西都灰暗的游戏，也不是单纯依靠黑色和金属装饰构建的黑暗幻想。

它是一套以古老文明为背景、以半写实幻想造型为基础、以可信材质和电影感光照塑造空间、以古典而清晰的 UI 传递秩序，并允许鲜明角色、丰富文明与奇异场景共存的视觉体系。

**世界可以有丰富的颜色，角色可以拥有鲜明的个性，场景可以拥有截然不同的情绪；但它们必须遵循同一套视觉语言。**

最终目标：让玩家感受到自己不是在操作一套普通的战棋 UI，而是在一个古老、沉默、丰富而逐渐衰败的世界中，指挥一场仍然遵循秩序的战争。
