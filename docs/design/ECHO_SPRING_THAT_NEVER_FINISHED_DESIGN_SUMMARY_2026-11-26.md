## 一、赛季定位与长期组织方式

| 主题 | 已确认选择 | 说明 |
| --- | --- | --- |
| 赛季主题组织 | A：全新主题世界 | 每个赛季带来一个全新主题世界；各主题世界彼此独立，但属于ECHO整体世界观。 |
| 内容开放方式 | C：混合开放 | 赛季开启时开放大部分常规探索内容；主线区域、隐藏地点和特殊挑战通过进度、探索发现或特殊条件开放。 |
| 赛季持续时间 | A：1～2个月 | 建议以6周为标准，可按内容规模在4～8周之间调整；现实更新周期不等于玩家游玩时限。 |
| 赛季并行方式 | C：当前赛季与历史赛季并存 | 当前赛季提供完整特殊玩法；历史赛季永久保留剧情、普通关卡与档案，特殊机制可通过复刻或历史挑战开放。 |
| 赛季难度体系 | B：每个赛季独立难度 | 不同主题有自己的难度曲线，不要求后续赛季必然更难，避免数值膨胀。 |
| 赛季难度解锁 | 待定 | 此前推荐C：初阶和进阶开放，高阶与深层通过进度解锁；用户尚未作最终选择。 |

赛季时间与玩家进度分离：不应因玩家错过现实日期而失去重要剧情。历史赛季应保留主要剧情与普通探索内容。

## 二、「未尽之春」世界观与故事

| 项目 | 当前设定 |
| --- | --- |
| 赛季名称 | 「未尽之春」（The Spring That Never Finished）为当前使用名称，尚未收到明确的正式定名确认。 |
| 主角 | 樱。 |
| 身份 | 归乡者。 |
| 故事氛围 | 唯美与悲剧。 |
| 命名方向 | 诗意。 |
| 核心舞台 | 一个永远停留在春天的故乡。 |

世界观核心草案：樱曾经生活在这片故乡。某场未知灾难发生后，世界停止变化，春天没有结束，樱花始终不凋谢，某些人影不断重复过去的生活。樱归乡后发现，故乡已经无法回到记忆中的样子。

核心谜团：世界为什么永远停留在春天？某种力量似乎保存了灾难发生前的瞬间，导致记忆与真实逐渐脱节。樱与灾难存在深层联系，但真相尚未确定。

| 章节草案 | 叙事作用 |
| --- | --- |
| 故园来信 | 抵达故乡，建立归乡与熟悉感。 |
| 旧日回声 | 发现现实与记忆之间的矛盾。 |
| 花落之前 | 逐渐接近灾难真相。 |
| 未尽之春 | 面对最终选择。 |

区域美术/地点名称草案：落樱村、千枝神社、浮世旧城、永春之庭。它们是当前美术与世界构想，不应在未完成区域结构审定前视为最终地图清单。

结局方向尚未选择。曾讨论的方向包括：接受离别、让时间重新流动；留下守护、成为世界守护者；迎来新的春天、让世界以新形式延续。当前建议暂不锁定结局，让樱最终作出选择，玩家陪伴她而非替她决定。

季节机制草案：「凋零与回响」——区域地形、道路或敌人行动可能短暂重现过去状态。该机制尚未批准。

## 三、五区域冒险结构

【已确认总体结构】一局冒险由五个连续区域构成。第一区域为初始区域；第二区域末尾设置Boss；通过后进入第三区域；第三区域开始难度提升，第四区域继续提升；第五区域难度最高，最终Boss战胜利后本局结束。

| 顺序 | 暂定区域名 | 难度定位 | 进度说明 |
| --- | --- | --- | --- |
| 1 | 春之境 | 初始难度 | 当前版本重点设计与交付的区域。 |
| 2 | 夏之境 | 初始难度 | 区域末尾有第一个Boss；尚未展开详细设计。 |
| 3 | 秋之境 | 难度提升 | 进入更高难度阶段。 |
| 4 | 冬之境 | 进一步提升 | 继续提高战斗与资源压力。 |
| 5 | 终焉之境 | 最高难度 | 最终Boss；胜利后本局结束。 |

区域名称与主题方向是当前工作称呼；除春之境外，后续区域具体内容尚未设计完成。

用户特别确定：当前这次大更新只做到春之境结束。春之境探索体力耗尽时，界面提示强制进入夏之境；但由于后续内容尚未解锁，实机应提示「后续内容尚未解锁」，随后结束探索并返回主界面，不实际进入夏之境。

## 四、双模式与统一存档

【已确认架构决定】ECHO包含两种正式玩法模式，两者使用同一份玩家存档，但模式内玩法数据彼此隔离。

| 模式 | 定位 | 数据范围 |
| --- | --- | --- |
| 教程模式 | 保留现有三个教程关卡与原有玩法。 | 教程关卡进度及原有玩法规则。 |
| 未尽之春 | 独立的五区域赛季冒险玩法。 | 赛季关卡进度、局内资源、战斗规则与结算。 |

- 共享玩家身份、角色解锁和全局资料。

- 在一个模式解锁角色，另一个模式也能识别。

- 花钿、补给、遗物等模式专属资源不跨模式混用。

- 公共底层可共享；两种模式的玩法系统保持独立。

- 不得为了适配未尽之春而破坏现有教程模式。

设计决定不等于开发授权。正式开发前必须检查现有代码兼容性，按独立分支、测试、CI与PR审核流程推进。

## 五、局内资源与经济体系

### 5.1 基础资源

| 资源 | 已确认规则 | 补充说明 |
| --- | --- | --- |
| 花钿 | 单一通用货币。 | 常规商店交易使用花钿。 |
| 补给 | 全队共享，不按角色分别携带。 | 可用于恢复、特殊事件和交易。 |
| 四时花露 | 四种资源共享总储存上限。 | 四种名称方向为春露、夏辉、秋实、冬霜；完整用途与数值仍待定。 |
| 记忆残页 | 不设置储存上限。 | 用于记忆拼合、特殊交换和共鸣事件的用途为设计方向。 |
| 遗物 | 无数量上限。 | 不设负重、遗物槽位或携带惩罚。 |

### 5.2 恢复规则

- 仅在区域转换时恢复；战斗结束不自动恢复生命。

- 区域转换恢复由玩家自行选择角色。

- 补给可自由分配给恢复、特殊事件和交易。

- 基础恢复采用全队共享额度，玩家自由分配；固定免费恢复额度的具体数值尚未确定。

- 每次区域转换获得基础休整/恢复；补给用于额外恢复或其他用途。

### 5.3 跨区域与失败结算

- 本局临时资源、遗物与构筑原则上在冒险失败时清空；部分成果按规则转化为局外奖励。

- 永久剧情、图鉴、地图发现和解锁进度保留。

- 具体转化公式、保留比例和失败奖励数值尚未确定。

- 四时花露在本局内跨区域保留；四种花露共享总储存上限。

### 5.4 四时花露容量

- 容量满时不能无声丢弃新花露，需提示玩家使用、兑换或放弃本次新花露。

- 基础容量固定，不随区域自动成长。

- 容量可通过遗物或特殊事件提升；容量提升不自动赠送花露。

- 容量提升建议在本局持续，避免超限资源被强制丢弃。

### 5.5 遗物获得方式

| 来源 | 获得方式方向 |
| --- | --- |
| 普通战斗 | 概率随机获得。 |
| 精英战斗 | 多件随机遗物中选择一件。 |
| 区域Boss | 从区域专属奖励中选择或按专属规则获得。 |
| 商人 | 使用花钿购买指定遗物。 |
| 特殊事件 | 根据事件选择获得独特遗物。 |
| 隐藏挑战 | 固定或条件奖励。 |
| 记忆事件 | 通过记忆残页或剧情条件获得。 |

具体掉落池、概率与数量尚未全部定稿。

## 六、藏品与记忆残页

### 6.1 藏品规则

- 被动藏品自动生效；主动消耗品由玩家决定使用时机。

- 藏品不能重复获得；已拥有藏品不应再次出现在奖励池或商店。

- 被动藏品每局最多获得一件；重复抽中时重新抽取其他符合条件的藏品。

- 即时资源类藏品领取后视为已获取，原则上不重复抽取。

- 不通过重复获得同一藏品来叠加强化。

- 如果玩家已拥有藏品池大部分藏品，应扩大候选范围或提供其他资源奖励，避免无效选项。

- 主动消耗品能否持有多份、携带数量上限尚未确认。

- 条件触发型藏品曾建议视为自动生效的被动藏品，但尚未单独确认分类。

### 6.2 藏品触发时机与稀有度

建议统一检查的触发时机：获得时、战斗开始、回合开始、行动执行、受到伤害、击败敌人、战斗结束、区域转换、商店生成、特殊事件触发。

稀有度方向：普通、稀有、史诗、传说。春之境精英奖励明确不开放史诗和传说；Boss专属奖励池允许普通、稀有、史诗，传说极低概率。

藏品之间自然组合与少数隐藏联动曾作为建议提出，尚未明确确认。

### 6.3 记忆残页

- 不设置储存上限。

- 建议用于记忆拼合、特殊交换和共鸣事件。

- 永久发现的剧情记忆保留；未使用残页作为本局临时资源参与结束结算。

- 故乡、归途、灾厄、未尽四种残页分类是候选设计，尚未正式确认。

## 七、商店系统

商店包含购买、出售、服务三项功能/页面。春之境商店暂称「春日行商」。

### 7.1 库存生成与类别

- 采用全局藏品池、区域候选池与商店随机库存组合。

- 商品生成采用「分类保底 + 权重随机」。

- 曾提出6个库存栏位：基础补给1、战斗消耗品1、被动藏品1、季节商品1、随机2；栏位数量尚未确认。

- 某类别缺少候选时，回退到随机池。

- 春季商品方向：恢复、基础补给、探索。夏季：攻击强化、能量辅助。秋季：经济与资源转换。冬季：防护、保存、恢复。终焉：高级综合构筑与四季藏品。

### 7.2 库存与刷新

- 商店库存生成后锁定；离开后再次进入，商品种类与状态保持不变。

- 购买后库存减少；已购买商品不会因刷新重新加入库存。

- 每件商品独立记录库存数量。普通补给和战斗消耗品可以多份；普通/稀有/特殊遗物一般一份，仍需与藏品不重复规则统一。

- 允许付费刷新；刷新费用随当前商店刷新次数递增。

- 刷新会重新生成商品种类、稀有度、库存数量和随机栏位，仍使用当前区域候选池。

- 刷新费用示例15、25、40、60、85仅为示例，不是正式数值。

- 进入下一家商店刷新费用重置。当前商店的出售记录与已完成服务建议保留。

### 7.3 价格与事件影响

- 商品使用固定基础价格；藏品或事件可修正价格。

- 区域本身不自动涨价或降价。

- 经济事件只影响下一家商店；效果到达商店时应用，离开该商店后结束。若尚未遇到商店，效果持续等待。

- 经济事件可影响价格、库存、品类权重、稀有度权重和刷新费用；多事件修正叠加规则待定。

### 7.4 出售规则

- 玩家可以出售不需要的藏品换取资源。

- 出售类型、价格与不可出售清单尚未最终确定。曾建议剧情关键物品、记忆残页、永久剧情记录和部分特殊剧情遗物不可出售。

- 出售可能破坏藏品组合效果时，出售前应提示。

- 出售不自动增加商店购买库存；购买价和出售价独立计算，避免无成本套利。

- 交易应采用原子性结算：成功或失败，不出现扣款但未交付等中间状态。

## 八、春之境地图与探索规则

### 8.1 地图基本形式

- 春之境采用自由探索网格地图。

- 完整网格和相邻关系始终显示，无迷雾。

- 普通地点公开；隐藏地点在满足条件前不显示，满足条件后显现。

- 抵达地点后由玩家主动交互，不自动触发。

- 地图上的队伍作为整体移动，地图上只显示一个统一队伍标记。

### 8.2 探索体力

| 规则 | 内容 |
| --- | --- |
| 初始与上限 | 初始10点；上限固定10。 |
| 移动消耗 | 每移动1格消耗1点；N格消耗N点。 |
| 独立性 | 探索体力与战斗AP完全独立，不互转、不互耗。 |
| 往返 | 允许自由往返，前后移动均按每格1点消耗。 |
| 恢复 | 可通过特定事件或藏品恢复，不能超过10点。 |
| 耗尽 | 体力耗尽后强制结束春之境；先完成抵达和允许的交互窗口，再触发强制结束。 |
| 主动结束 | 可主动结束探索并进入下一地区；确认前显示剩余体力，剩余体力作废且不转移。 |
| 区域上限 | 不能通过藏品或事件提高探索体力上限。 |

### 8.3 地点选择与移动

- 点击地点只展示地点类型和从当前位置前往所需探索体力（最短移动格数）；不展示描述、访问历史或重复访问状态。

- 选择地点时显示从当前位置到目标地点的最短路径高亮及体力成本；路径展示不自动移动。

- 点击前往后按逐格移动动画执行；每经过一格扣1点体力。

- 移动过程中不接受重复移动指令。移动操作应原子化，避免部分扣体力或重复扣除。

- 抵达后等待玩家主动交互；当前格子可直接交互，不消耗体力。

- 体力不足的地点显示灰色，仍可查看类型和所需体力，提示不足，但不允许确认移动。

- 若体力恰好耗尽并抵达地点，仍允许在当前位置主动交互；之后触发强制结束。

### 8.4 地图视觉与UI

| 项目 | 已审定方向 |
| --- | --- |
| 整体风格 | minimal：简洁战棋网格地图，清晰易辨识，春日柔和配色；不做复杂绘卷或2.5D等距地图。 |
| 网格 | grid：明确显示完整5×5网格，地点图标对应地格，当前位置和完成状态清晰。 |
| 顶部资源栏 | fixed：常驻显示队伍头像与生命、花钿、补给、四种四时花露与总容量、记忆残页、探索体力/上限。 |
| 动态效果 | subtle：少量花瓣飘落、柔和光照、当前地点轻微高亮、适度交互动画；不使用大量粒子、复杂镜头或强动画。 |
| 缩放 | buttons：仅加号、减号、恢复默认缩放；不支持双指捏合；不改变坐标、地点位置和体力消耗。 |
| 资源详情 | tap：点击顶部资源图标或数量展开详情面板，显示数量、容量和用途；查看不自动消费。 |

## 十、春之境事件系统

### 10.1 风险原则

- 允许事件出现负面结果。

- 风险有提示等级：安全、未知、危险、高风险；提示不完全剧透。

- 风险与收益应匹配；重要进度不应被随机永久摧毁。

- 玩家可能损失资源、遭遇陷阱或触发额外战斗。

### 10.2 事件候选池

| 事件 | 类型 | 选项/效果方向 |
| --- | --- | --- |
| 受困的商队 | 经济 | 帮助、拒绝或搜寻货物；影响下一家商店价格。 |
| 无人祭拜的神龛 | 资源 | 献花钿、献补给或取供品；存在风险。 |
| 被封存的箱子 | 高风险 | 花钿开启、补给强开或暴力破坏；可能触发陷阱战斗。 |
| 无人的营地 | 生存 | 消耗补给休整、搜寻物资（可能埋伏）或离开。 |
| 林间的异响 | 战斗 | 调查触发额外战斗、布陷阱降低难度或绕路离开。 |
| 石门之后 | 探索/隐藏 | 寻找机关、强行打开或放弃；可能发现隐藏宝箱。 |
| 失落的旅人 | 人物剧情 | 帮助寻找行囊获得记忆残页；索要报酬获得花钿；偷行囊获得随机藏品但可能损失补给。 |
| 旧时代的商契 | 经济 | 签约影响下一家商店降价；拒绝无变化；撕契换花钿但下一家商店部分涨价。 |
| 神秘收藏家 | 藏品交易 | 支付花钿获得随机藏品；交出允许交易的藏品换更高稀有度随机藏品；或拒绝。 |

- 永久图鉴、地图发现等局外进度由独立系统管理；事件发现永久档案是否重置仍待确认。

## 十一、战斗流程、部署与战场通用规则

### 11.1 部署阶段

- 每场战斗在正式进入回合前，玩家从待部署区将角色放置到战场合法格子，自由选择初始位置。

- 战场、敌人、障碍和宝箱生成后，进入部署阶段。

- 玩家只能在指定部署区部署，不能放入敌方区域；部署区形状可变化。

- 部署阶段不消耗AP、不计回合、不触发敌人行动。

- 每格只能部署一名角色，不可部署在障碍格、存活宝箱或结界节点所在格；所有占格对象统一禁止部署。

- 确认前可调整位置，建议允许撤回待部署区；点击确认部署后才正式开始战斗。

- 战斗开始触发的藏品效果不在部署阶段触发，而在正式战斗开始时触发。

- 普通敌人位置和形象公开；特殊敌人按战斗设定决定；隐藏敌人/伏击单位位置隐藏，满足条件后才显现；部署阶段不能选中或攻击隐藏单位。

### 11.2 战斗结束与跨战斗状态

- 战斗胜利后返回原地图位置，保留剩余探索体力；不返还已经消耗的探索体力。

- 战斗结束后生命值继承，不自动恢复。

- 战斗中获得的异常状态全部清除；战斗临时增益、临时减益清除。

- 最大生命值、角色永久属性、装备效果、藏品提供的持续被动效果保留。

- 以上规则适用于普通、精英和Boss战。

### 11.3 战斗失败与续行

- 普通/精英战斗失败时，玩家可选择消耗补给续行；每个区域最多续行一次，进入下一地区后次数重置。

- 续行固定消耗3补给，队伍恢复到最大生命值的30%，回到战败前所在地图格，保留剩余探索体力。

- 扣补给与恢复生命必须原子性结算，成功才扣除。

- 战败节点标记完成并灰显，不可再次选中；战败不获得该场战斗奖励。

- 补给不足不能续行，立即结束本局冒险并按失败结算。

- Boss战失败续行已明确为特殊规则，不直接套用普通战斗的3补给规则；具体特殊规则待定。

## 十二、宝箱系统

- 宝箱出现在战斗场地中，拥有独立生命值；受到范围攻击波及时正常扣除生命，生命归零后销毁。

- 战斗开始后立即显示宝箱位置，不隐藏、不需要发现。

- 每场战斗的位置随机从合法格生成，不与单位或障碍重叠，不在不可达格。生成后本场战斗内固定。

- **单体攻击只选择存活的玩家角色作为目标，不主动选择宝箱。**

- **范围攻击以玩家角色为主要攻击目标；宝箱若恰好位于该次范围攻击覆盖格内，可以受到波及。**

- 范围攻击波及宝箱时正常结算宝箱耐久与摧毁事件；宝箱不会因为被范围攻击波及而免疫伤害。

- 宝箱若在战斗结束时仍存活，结算固定10花钿。

- 宝箱不分种类或稀有度，不属于藏品池；受伤但未摧毁仍可领取奖励。

- 宝箱以偏低概率随机出现，不是每场必出；每场独立判定。具体概率未定。

- 宝箱是全局通用战场经济目标，所有主题赛季可使用。

### 15.1 凋樱剑主

- 普通攻击「樱刃」：相邻正交格单体物理攻击，倍率0.80；无异常状态，不击退；优先攻击可正常攻击的玩家角色并预告目标。

- 专属技能「樱落领域」：指定合法攻击区域，提前显示危险格，之后发动范围斩击；范围内角色受到伤害，覆盖地格进入凋零状态。

- 技能参数方案：伤害倍率1.00；范围3个相邻地格；凋零持续2个完整回合；凋零伤害倍率0.25；冷却3回合。

- 凋零地格：进入或停留会受伤；每名角色每个玩家回合最多触发一次；不阻挡移动/视线，不清除、不叠加持续时间；到期恢复正常。

- 行动：自由移动并主动接近玩家；建议每次最多移动2格。

### 15.2 千枝神将

- 普通攻击「重盾击」：相邻正交格单体物理攻击，倍率0.70；中等偏低伤害，无异常、不击退，攻击前预告目标。

- 专属机制「春之结界」：战场生成2个结界节点，每个节点独立生命值700；玩家可攻击摧毁。节点占格阻挡移动但不阻挡视线；不击退、不主动攻击、不重新生成。

- 每个存活节点为Boss提供+80防御；节点摧毁后对应防御强化永久失效。节点不单独掉落奖励。

- 节点从Boss周围合法格随机选择，不与单位或障碍重叠；部署阶段不激活结界，战斗开始后才可攻击节点。

- 专属技能「结界守护」：Boss获得临时护盾；基础护盾为最大生命值6%，每个存活节点额外增加最大生命值2%；持续2回合，冷却3回合；不造成伤害、不打断、不叠加。

- 玩家可忽略节点直接攻击Boss；破坏节点会明显降低Boss防御和护盾效果。

- 行动：最大移动1格，不积极追击，优先守护结界区域，优先攻击近距离目标。

### 15.3 春痕回响

- 普通攻击「花影弹」：远程单体魔法攻击，倍率0.65；优先攻击可正常攻击的玩家角色并预告目标；不附加异常、不击退、不穿透障碍，遵守视线规则。

- 专属机制「残春领域」：技能生成2～3个相邻残春地格；出现前显示危险范围；进入或停留造成少量伤害；持续2个完整回合后消失；不阻挡移动/视线、不叠加。

- 专属技能「春痕绽放」：范围3个相邻地格，预告后造成倍率0.75法术伤害并生成残春地格；冷却3回合；不附加其他异常。

- 行动：最大移动1格，倾向保持距离；玩家靠近时尝试拉开距离，但不无限后退；无合法攻击目标时调整位置。

### 15.4 Boss通用规则与奖励

- 使用与普通战斗相同大小的基础棋盘；Boss位于敌方合法部署区域。

- 部署阶段Boss不行动、不发动技能；正式战斗开始后按规则行动。

- 普通攻击和技能均提前预告目标/危险范围；玩家离开预告范围后不受该次范围攻击伤害。

- 不因无合法目标而强行施放技能；击败Boss立即结束战斗。

- Boss战失败续行采用特殊规则，具体尚未设计完成。

- Boss胜利奖励方向：固定花钿和补给；随机专属奖励直接随机获得一件；Boss专属池允许普通、稀有、史诗，传说极低概率；另有概率获得花钿、补给或战斗消耗品额外奖励。具体数量与概率待定。

## 十六、结算、失败与本局存档

### 16.1 战斗结算

- 战斗胜利：领取正常奖励，回到原地图位置，保留探索体力；节点完成且不可重复挑战。

- 战斗失败：不获得该战斗奖励；普通/精英战按区域最多一次的3补给续行规则处理；Boss战续行另行制定。

- 宝箱存活至战斗结束，额外结算10花钿；宝箱被摧毁则无该奖励。

### 16.2 本局保存

中途退出后完整恢复本局状态，至少包括：地图模板、当前位置、探索体力、地点完成状态、随机事件内容与选择、隐藏地点位置和触发状态、商店商品与剩余库存、购买记录、刷新记录、已完成服务、跨区域事件标记和待触发内容、当前队伍状态与资源。恢复时不重新抽取地图、事件或商店库存。

### 16.3 冒险失败与局外保留

冒险失败时，本局临时资源、遗物和构筑原则上清空；部分成果按尚待确定的规则转化为局外奖励。永久剧情、图鉴、地图发现与解锁进度保留。跨局事件选择与关系标记重置。

## 十八、开发工作流与授权边界

本文件只记录设计，不是开发授权。未获用户明确授权前，不修改仓库、不创建分支、不提交代码、不创建PR。

1. 开发前只读检查现有代码、仓库结构、相关模块和正在进行的分支。

1. 提交代码冲突、功能冲突、接口冲突、架构冲突和回归风险分析报告。

1. 方案确认后，在独立Git分支开发；优先新增模块或扩展接口，保护原有功能。

1. 解决冲突并运行构建、自动化测试、静态检查等。

1. 提交独立分支并创建PR，说明修改内容、文件范围、兼容性和测试结果，等待CI。

1. CI通过后交由Sencly决定是否合并；助手不自行合并main，不绕过CI。

1. 若出现无法安全处理的冲突、需删除旧功能或重大架构改变，先暂停并询问用户。

项目边界：未尽之春与教程模式共用玩家身份和角色解锁等全局资料，但赛季玩法、局内资源、进度与结算隔离。任何实现均须遵循这一边界。
