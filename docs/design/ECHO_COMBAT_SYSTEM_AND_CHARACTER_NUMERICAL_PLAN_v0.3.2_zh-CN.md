# 第一部分：战斗系统总纲

## 1. 战斗定位

ECHO采用网格战棋式回合制战斗。战斗强调：
- 可读、可预判的敌方行动。
- 全队共享行动点带来的资源分配。
- 角色之间的战术协作。
- 位置、射程、视线和障碍带来的空间决策。
- 技能、状态与角色专属资源形成的战术循环。

战斗系统应优先保证规则清晰、结果可预测、反馈明确。随机命中与随机暴击不是基础战斗的必要组成部分。

## 2. 队伍结构

- 常规战斗队伍为5名角色。
- 五名角色共同使用同一份行动点预算。
- 队伍不强制采用固定职业配比。
- 玩家可以自由组合职业，也可以重复选择同一职业。
- 角色可以在玩家回合内自由切换操作。

## 3. 职业体系

| 职业 | 英文名 | 主要职责 |
|---|---|---|
| 防卫 | Bulwark | 承伤、保护队友、维持前线 |
| 火力 | Sentinel | 稳定输出、集中击杀 |
| 尖兵 | Vanguard | 突袭、侧翼切入、机动压制、特殊目标处理 |
| 支援 | Support | 治疗、增益、削弱与团队支援 |

职业与武器类型分离，不强制绑定。

樱目前定位为尖兵。她可以具有辅助性和易上手的自动追击机制，但不因此改变职业归属。她的“保姆性质”主要体现为稳定输出、自动追加攻击和较低操作负担，而不是治疗或护盾职责。

# 第二部分：基础战斗规则

## 4. 共享AP

- 每个玩家回合全队共享5 AP。
- 5 AP由五名角色共同使用，不是每人各有5 AP。
- 玩家回合开始时恢复AP。
- 玩家可以自由选择角色和行动顺序。
- 同一角色可以在同一回合内连续行动。
- 不设置统一的单角色行动次数上限。
- AP不足时不能执行行动，不允许透支。
- 玩家可以提前结束回合，剩余AP作废，不结转。
- 目标确认前可以取消；行动确认并执行后不可撤销。

### 行动消耗基线

| 行动类型 | AP消耗 | 说明 |
|---|---:|---|
| 移动 | 1 | 单次移动最多2个正交格 |
| 普通攻击 | 1 | 具体攻击参数按角色定义 |
| 普通主动技能 | 暂定1 | 技能可另设限制 |
| 强力主动技能 | 暂定2 | 技能可另设限制 |
| 终极技能 | 暂定2 | 另需5点个人终极能量 |
| 特殊技能 | 单独定义 | 必须在技能规格中写明 |

主动技能默认可在同一回合重复使用；具体技能可以单独规定每回合使用次数或冷却。

连续移动允许存在：每次移动消耗1 AP，最多移动2格；移动可以与攻击或技能穿插。

## 5. 网格移动

- 仅允许正交移动：上、下、左、右。
- 不允许斜向移动。
- 单次移动最多2格。
- 移动消耗1 AP。
- 不能穿过友方、敌方、墙壁、障碍物或倒地角色。
- 目标格必须为空。
- 移动路径必须完整合法。

## 6. 攻击空间规则

### 近战攻击
- 近战普通攻击只能攻击正交相邻敌人。
- 斜向相邻不算近战相邻。
- 不能隔着其他单位、墙壁或障碍物攻击。

### 远程攻击
- 远程攻击同时受到射程和视线限制。
- 墙壁与大型障碍物阻挡视线。
- 普通单位是否阻挡视线由具体武器或技能定义。
- 特殊技能可以具有更远射程、穿透或无视视线等独立规则。

## 7. 敌方行动预告

- 敌方行动预告在玩家回合开始时生成。
- 敌方按照固定且可见的顺序执行。
- 预告必须与实际执行使用同一份权威行动定义。
- 敌人死亡后，其尚未执行的行动预告立即取消。
- 预告失效时按已批准规则取消，不得擅自重新选择目标。

## 8. 普通敌人与战斗节奏

普通敌人通常需要3–5次有效的基础普通攻击才能击败。

技能爆发或队伍集火可以更快完成击杀；不要求敌人必须存活3–5个完整回合。

# 第三部分：伤害、状态与角色成长

## 9. 伤害类型

直接伤害初步分为：
- 物理伤害。
- 法术伤害。
- 真实伤害。

默认攻击必定命中，不设置传统RPG随机命中率或闪避率。攻击是否成功由射程、视线、范围、阻挡和技能条件决定。

普通攻击默认不带随机暴击。被动、主动技能或模组可以赋予暴击能力；暴击可以采用固定条件触发，倍率由角色或技能定义。

## 10. 伤害公式的代码核对结论

### 10.1 当前main分支的原始伤害公式

当前仓库实现：

原始伤害 = round(攻击力 × 技能倍率)

攻击力或倍率小于等于0时，原始伤害为0；正数计算结果至少为1。

### 10.2 当前main分支的抗性公式

当前仓库实现：

最终抗性处理伤害 = floor(原始伤害 × 1000 ÷ (1000 + 对应抗性))

原始伤害为0时结果为0；正伤害至少保留1。

- physical使用DEF。
- magical使用Magic Resistance。
- 当前非physical、非magical类型会走0抗性分支。

这意味着当前实现的非物理、非法术类型会绕过DEF和魔法抗性。未来应以明确的伤害类型枚举或合法性检查代替未知类型静默绕过防御。

### 10.3 当前完整伤害处理顺序

当前BattleActor实现的处理顺序：

1. 根据伤害类型选择DEF或Magic Resistance。
2. 应用抗性惩罚，得到有效抗性。
3. 使用递减收益公式处理抗性。
4. 依次处理额外减伤百分比。
5. 处理个人防御状态的最终减伤。
6. 护盾吸收伤害。
7. 剩余伤害扣除HP。
8. HP归零时判定单位被击败。

额外减伤采用顺序计算，不把不同减伤百分比直接相加。每次减伤后向下取整，正伤害至少保留1。

护盾优先于HP承伤；护盾不足时，溢出部分扣除HP。

### 10.4 当前公式的示例

| 项目 | 输入 | 结果 |
|---|---|---:|
| 原始伤害 | ATK 2000，倍率1.5 | 3000 |
| 抗性处理 | 原始伤害3000，抗性500 | 2000 |
| 物理伤害 | 原始伤害2000，DEF1000 | 1000 |
| 法术伤害 | 原始伤害2000，法抗500 | 1333 |

这些是当前仓库公式的数学示例，不代表樱的0.3属性已经适配。

### 10.5 当前代码的伤害类型与RES差异

当前代码的DEF和Magic Resistance使用整数抗性；樱的候选RES采用百分比表达。

两者不能直接等同。

若沿用K=1000的递减收益公式，10%减伤对应的抗性约为111.11点：

R = 1000 × 0.10 ÷ (1 - 0.10)

该换算仅用于解释单位差异，不代表已经批准把樱的RES 10%转换为111点抗性。

**待批准：** 0.3最终采用百分比抗性、整数抗性，还是保留递减收益公式并建立统一转换规则。

### 10.6 伤害系统后续要求

- 普通攻击和技能攻击使用统一伤害计算入口。
- 伤害类型必须合法且明确。
- 每个技能必须声明伤害类型和倍率。
- 技能倍率与角色基础属性分离。
- 增伤、减伤、暴击和护盾有唯一明确的计算顺序。
- 伤害显示值必须与实际扣除数值一致。
- 多段攻击每段独立计算伤害，但不得重复触发行动级效果。
- 真实伤害是否受到通用减伤、护盾保护，需单独明确。
- 不得将旧原型专属的防御机制自动推广为全角色规则。

## 11. 状态与护盾

状态效果候选包括燃烧、流血、眩晕、减速、破甲等。伤害与状态分层处理，每种状态分别定义叠加和持续规则。

护盾规则的已确认方向：
- 护盾为独立数值。
- 受到伤害时优先消耗护盾。
- 默认不叠加。
- 角色特殊技能可以突破默认限制。
- 持续时间由技能自定义。

重复获得护盾时的覆盖、刷新或替换规则仍需按具体系统批准，不能把守誓者旧原型的专属15%最大HP护盾上限自动套用到所有角色。

## 12. 倒地与复活

- 角色HP降至0时立即倒地。
- 倒地角色不能行动。
- 倒地角色仍占据原格。
- 特定技能可以复活角色。
- 复活后回到原格。
- 复活后的HP与可复活次数由具体技能定义。

## 13. 终极能量

- 每名角色拥有独立终极能量。
- 能量范围为0–5。
- 玩家回合开始时，存活友方角色获得1点。
- 成功主动行动后，每名角色每回合最多额外获得1点。
- 终极技能消耗5点个人能量与2 AP。

**待确认：** 普通攻击是否属于额外终极能量获取的主动行动。

## 14. 角色成长

- 角色获取时即拥有完整基础数值。
- 不设置传统角色等级与经验升级。
- HP、ATK、DEF、RES不通过反复刷经验无限提升。
- 成长主要通过技能升级、技能专精、专属模组、特殊天赋改变战术能力。
- 信赖主要用于角色档案与故事内容。
- 潜能、晋升、技能升级/专精、模组的具体机制仍待确认。
- 避免重复获得角色直接转化为战斗优势。

# 第四部分：角色技能统一结构

## 15. 统一技能结构

每名角色拥有：
1. 普通攻击。
2. 被动天赋。
3. 主动技能一。
4. 主动技能二。
5. 终极技能。

普通攻击消耗1 AP。倍率、攻击范围、伤害类型与终极能量交互由角色技能规格定义。

# 第五部分：樱的角色规格

## 16. 角色定位与视觉背景

- 姓名：樱。
- 定位：尖兵（Vanguard）。
- 青年、高大女性。
- 气质柔和忧伤但具有杀气，仿佛背负沉重过去。
- 深红色长发。
- 巫女风格服装：象牙白上衣、深朱红袴裙。
- 使用异形古代文明长剑，剑身暗红发光，剑柄悬挂樱花穗。
- 背景结合失落的守祀者与古代文明遗留者：曾守护古老遗迹与仪式；某场与失落纪元有关的灾难摧毁其守护的一切。
- 灾难具体经过与长剑秘密仍未确定。
- 战斗风格迅捷精准，以突袭和斩击解决敌人。
- 普通攻击动作采用精准突刺：身体略前倾，长发和衣袖后扬，留下细长暗红剑痕与少量樱花状红色粒子。

## 17. 樱候选基础面板

|---|---:|
| HP | 1800 |

## 18. 技能名称

| 类型 | 名称 |
|---|---|
| 普通攻击 | 穿花 |
| 被动天赋 | 花信 |
| 主动技能一 | 流风 |
| 主动技能二 | 落英 |

机制名称：
- 战斗资源：剑意。
- 敌人标记：残香。
- 自动追加攻击：回锋。
- 资源满层状态：极意。

## 19. 剑意与极意

### 基础规则
- 剑意上限4层。
- 玩家回合开始时自动获得1层。
- 每次完成一次移动指令，获得1层。
- 每次成功执行一次攻击行动，获得1层。
- 每击败一名敌人，额外获得1层。
- 每个玩家回合第一次触发回锋时，额外获得1层。
- 剑意超过4层的部分舍弃。
- 达到4层时自动进入极意。

### 0.3批准的行动获取上限
- 每回合通过行动事件获取剑意最多3层。
- 回合开始自动获得的1层不计入该限制。
- 移动、攻击、击杀、首次回锋等非回合开始事件统一计入3层上限。
- 该限制是已批准的测试基准，仍需在战斗模拟中验证循环是否过度受限。

### 极意消耗
- 极意强化下一次主动技能：流风或落英。
- 使用强化主动技能后消耗全部4层剑意。
- 普通攻击不消耗极意。
- 终极技能不消耗现有剑意，也不清除极意。
- 极意强化技能使用后的新剑意按正常获取规则处理，并遵守上限与每回合行动获取上限。

## 20. 残香

- 普通攻击与主动技能可以施加残香。
- 首次攻击目标没有残香时，只施加标记，不立即触发回锋。
- 攻击结算后施加或刷新标记。
- 残香持续3个敌方回合。
- 重复施加只刷新持续时间，不叠加层数。
- 终极技能暂不默认施加残香。
- 回锋本身不能施加残香。

持续时间必须在实现中明确映射到敌方回合边界，并通过连续回合测试确认不会多算或少算。

## 21. 回锋

樱攻击带有残香的敌人时，自动追加剑击。

### 基础规则
- 基础回锋伤害为普通攻击伤害的50%。
- 落英极意强化下回锋伤害提升至65% ATK。
- 回锋不消耗AP。
- 每次攻击行动最多对每个符合条件的残香目标触发一次。
- 不触发自身或其他被动追加攻击，防止无限连锁。
- 只攻击原目标，不转移目标。
- 必须满足攻击距离与视线条件。
- 回锋目标必须处于樱正交相邻1格。
- 如果原目标死亡或不再满足攻击条件，取消回锋。
- 多段攻击建议在整套攻击行动结束后统一检查回锋。
- 范围攻击可以对多个符合条件的残香目标分别触发一次回锋。

## 22. 主动技能一：流风

- AP消耗：1。
- 向指定方向突进最多2格。
- 对终点附近一名敌人发动斩击。
- 基础倍率：80% ATK。
- 命中后施加残香。

### 极意强化
- 原突进攻击后，再次追击，位移最多1格。
- 第二段追击可以选择新的方向与目标。
- 第二段只攻击一个目标。
- 追加剑击倍率：40% ATK。
- 如果目标已有残香，同一次行动中最多触发一次回锋（50%）。

第二段追击与多目标回锋的具体事件记录和结算时机必须在技能实现前写入测试用例。

## 23. 主动技能二：落英

- AP消耗：2。
- 指定方向扇形范围三段攻击。
- 每段30% ATK，总计90% ATK。
- 命中后施加残香。
- 已有残香的目标可以触发回锋。

### 极意强化
- 攻击范围扩大。
- 已有残香目标的回锋提升至65% ATK。
- 每个符合条件的残香目标每次行动最多触发一次回锋。

扇形格形尚未正式确定，不能在开发中擅自固定。

## 24. 终极技能：无尽芳华

- 消耗2 AP与5点个人终极能量。
- 固定范围群体剑舞，不逐个选择目标。
- 范围为以樱自身为中心的正交十字形，四个方向各延伸2格。
- 基础3段连续斩击与1段终结斩击，共4段。
- 前三段各20% ATK。
- 终结斩击40% ATK。
- 基础总倍率100% ATK。
- 每层剑意使终结斩击提高5% ATK。
- 满4层剑意时终结斩击额外提高20%，总倍率达到120% ATK。
- 残香目标受到额外追击，按基础回锋50%计算。
- 终极技能不施加残香。
- 不消耗剑意，也不清除极意。
- 终极技能作为一次攻击行动，多段攻击只获得一次攻击行动对应的剑意。

# 第六部分：统一事件结算规范

## 25. 当前代码架构核对

当前仓库采用模块协作的战斗架构，并非完整通用事件总线。

| 模块 | 当前职责 |
|---|---|
| BattleFlow | 回合切换、遭遇初始化与战斗结束 |
| SkillExecutor | 玩家技能校验与执行 |
| IntentPlanner | 生成敌方行动预告 |
| IntentResolver | 按预告顺序执行敌方行动 |
| DamagePipeline | 伤害处理及伤害后果 |
| BattleStatusCollection | 状态保存、刷新、叠加与移除 |
| BattleActor | 属性、护盾、HP与终极能量 |

当前架构以确定性直接函数调用为主。0.3可以沿用职责分离与集中伤害处理的思想，但需要扩展到五人队伍、共享AP、多段攻击和角色专属资源。

## 26. 通用攻击行动生命周期

### A. 行动确认
1. 检查角色状态。
2. 检查AP。
3. 检查技能可用性。
4. 检查目标、范围和视线。
5. 确认行动。
6. 扣除AP。

### B. 攻击执行
1. 创建唯一行动记录。
2. 固定原始目标与技能参数。
3. 逐段执行攻击。
4. 每段独立计算伤害。
5. 更新护盾与HP。
6. 处理目标倒地。
7. 记录击败事件。

### C. 行动后果
1. 处理状态施加与刷新。
2. 处理符合条件的被动。
3. 处理追加攻击。
4. 处理击杀资源。
5. 处理行动级资源。
6. 处理极意消耗与新剑意获取。
7. 检查战斗结束条件。
8. 完成行动记录。

具体技能可以定义特殊结算位置，但不能绕过基础合法性检查。

## 27. 事件分类

| 事件 | 说明 |
|---|---|
| TurnStart | 回合开始 |
| ActionStart | 行动开始 |
| MovementComplete | 移动完成 |
| AttackStart | 攻击开始 |
| AttackHit | 攻击命中 |
| DamageResolved | 伤害结算 |
| UnitDefeated | 单位被击败 |
| StatusApplied | 状态施加 |
| StatusRefreshed | 状态刷新 |
| FollowUpTriggered | 追加攻击触发 |
| ActionComplete | 行动完成 |
| TurnEnd | 回合结束 |

每个事件必须能够追溯来源、行动编号、目标与触发范围。

## 28. 行动级、目标级与段级触发

必须区分：

- 攻击段级：每一段伤害各自结算。
- 目标级：每个目标每次行动最多触发一次。
- 行动级：每次技能或攻击行动最多触发一次。
- 回合级：每回合最多触发一次。

不能仅写“触发一次”，却不说明一次是指一回合、一次行动、一个目标还是一段攻击。

## 29. 目标死亡处理

- HP降至0时立即进入倒地或死亡处理。
- 被击败单位不能继续执行不合法的后续攻击。
- 敌人死亡后，其尚未执行的行动预告取消。
- 对死亡目标不能继续触发回锋。
- 多段技能后续攻击段如何处理，必须由技能规格决定。
- 范围技能不能因为一个目标死亡而错误取消其他合法目标。

## 30. 樱的资源结算顺序

建议采用以下实现顺序：

1. 记录行动开始时剑意。
2. 检查是否处于极意。
3. 如果使用极意强化主动技能，锁定本次技能强化状态。
4. 执行技能攻击。
5. 处理击败事件。
6. 处理回锋。
7. 计算本次行动应获得的剑意事件。
8. 如果本次行动消耗极意，先执行极意消耗。
9. 按事件获取顺序发放新剑意。
10. 检查4层上限与每回合行动获取3层上限。
11. 更新极意状态。

这是用于避免极意消耗与新资源获取冲突的结算建议；若最终实现需要调整，必须先记录原因并审批。

## 31. 回锋防循环规范

每次攻击行动建立独立回锋记录，至少包含：
- 原始攻击者。
- 原始攻击行动编号。
- 原始目标。
- 已触发回锋的目标列表。
- 当前是否处于追加攻击阶段。

回锋不产生新的玩家AP行动，不触发自身，也不触发其他追加攻击。

## 32. 终极能量事件规则

- 每名角色独立拥有0–5点能量。
- 玩家回合开始时，存活友方角色获得1点。
- 每名角色每回合最多额外获得1点主动行动能量。
- 自动追加攻击不是新的AP行动。
- 多段攻击不重复获得行动级能量。
- 使用终极技能消耗5点能量和2 AP。

普通攻击是否获得额外能量仍待确认。
