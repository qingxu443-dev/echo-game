## 1. 角色概况

| 项目 | 设定 |
|---|---|
| 姓名 | 德斯特·李（Dest Lee） |
| 职业 | 火力（Sentinel） |
| 性别 | 女性 |
| 国籍 | 英国 |
| 身高 | 178 cm |
| 战斗定位 | 法术型群体爆发输出 |
| 核心机制 | 引燃 → 扩散 → 连锁爆炸 |
| 战术特点 | 大范围覆盖、连续伤害、密集敌群压制 |
| 主要弱点 | 生存能力偏低，依赖队友保护；不以控制能力见长 |

### 1.1 外观方向

- 过耳黑发，面容清冷。
- 佩戴带有徽章的军帽。
- 全身服装融合英伦西装与军服设计。
- 黑色长筒靴。
- 暗色服装搭配酒红色披风内衬。
- 手持点燃的香烟。
- 整体气质冷静、克制，具有英伦军官式的压迫感。

已制作正面、侧面、背面三视图概念设计。该视觉方向属于已确认的角色外观基线。

### 1.2 战斗体验

李的强度主要来自技能倍率、范围覆盖和状态联动，而不是高额基础攻击力。她擅长先铺设引燃，再通过死亡余烬和焚城指令放大敌方密集站位的代价。

她不应同时拥有优秀的生存、机动、控制和输出能力。其生存短板与队伍保护需求是职业定位的一部分。

## 4. 统一状态：引燃

引燃是李全部技能联动的基础状态。

### 4.1 状态规格

| 项目 | 规则 |
|---|---|
| 状态名称 | 引燃 |
| 最大层数 | 2层 |
| 持续时间 | 2个敌方阶段 |
| 叠加方式 | 增加层数，最多2层 |
| 刷新方式 | 每次重新施加/刷新时，整个状态持续时间刷新为2个敌方阶段 |

### 4.2 持续伤害

| 引燃层数 | 每个敌方阶段结束时造成的法术伤害 |
|---|---:|
| 1层 | 25% ATK |
| 2层 | 40% ATK（第一层25% + 第二层额外15%） |

### 4.3 计时与结算

- 两层引燃共享一个持续时间。
- 再次施加引燃会增加层数，并刷新整个状态持续时间。
- 已达到2层时再次施加不增加层数，只刷新持续时间。
- 敌方阶段中途新获得的引燃，从下一次敌方阶段结束时开始造成持续伤害。
- 已生效引燃在刷新时仍按既定阶段边界正常结算。
- 引燃持续伤害在敌方阶段结束时独立结算。

### 4.4 状态免疫

伤害免疫不自动等于引燃免疫。只有明确免疫引燃或免疫负面状态的单位才能抵抗引燃。护盾、伤害减免不会自动阻止引燃。

## 5. 技能01：黑焰射击

**类型：普通攻击**

### 5.1 基础规格

| 项目 | 规则 |
|---|---|
| AP消耗 | 1 AP |
| 攻击范围 | 以李为中心的3×3九格，并在上下左右方向各延伸1格，共13格 |
| 目标方式 | 只能选择一个敌方单位 |
| 伤害倍率 | 80% ATK |
| 伤害类型 | 法术伤害 |
| 暴击 | 设计上允许暴击，按李自身暴击属性判定 |
| 命中效果 | 施加1层引燃 |
| 引燃持续时间 | 刷新为2个敌方阶段 |

### 5.2 视线与地形

- 允许越过低矮障碍物。
- 高墙阻挡攻击视线。
- 目标必须处于有效攻击范围和视线内。

### 5.3 引燃规则

- 命中后施加1层引燃。
- 引燃最多叠加2层。
- 再次施加时增加层数，并刷新整个状态持续时间。
- 已有2层时再次施加不增加层数，只刷新持续时间。

### 5.4 死亡余烬联动

黑焰射击直接击杀敌方单位时，只有该单位在死亡瞬间带有引燃，才具备死亡余烬触发资格。

## 6. 天赋01：死亡余烬

**类型：被动天赋**

### 6.1 核心定位

符合资格的敌方单位死亡时，以死亡位置为中心产生范围爆炸，对周围敌人造成法术伤害并施加引燃。死亡余烬是李的核心连锁机制，但不会无限递归触发自身。

### 6.2 触发资格

触发资格在目标死亡瞬间检查。

| 击杀来源 | 死亡瞬间带有引燃 | 是否触发 |
|---|---:|---|
| 李的普通攻击、主动技能或终极技能直接击杀 | 是 | 触发 |
| 李的直接伤害击杀 | 否 | 不触发 |
| 引燃持续伤害击杀 | 是 | 触发 |
| 其他角色直接击杀 | 是 | 触发 |
| 李直接控制的召唤物击杀 | 是 | 触发 |
| 非李控制的召唤物击杀 | 是 | 不触发 |
| 机关或环境伤害击杀 | 任意 | 不触发 |
| 传送、移除、剧情特殊处决等非正常死亡 | 任意 | 不触发 |

补充：
- 召唤物必须具有明确的“李控制”标记，不能仅凭召唤来源推断归属。
- 死亡余烬不会触发其他击杀类效果。
- 死亡余烬爆炸造成的击杀不会继续触发新的死亡余烬爆炸。

### 6.3 爆炸范围与伤害

- 爆炸中心：死亡单位死亡时所在格子。
- 爆炸范围：完整3×3九宫格。
- 只伤害敌方单位和范围内可破坏物体。
- 不伤害友方单位。
- 高墙阻挡，低矮障碍物不阻挡。

| 目标相对位置 | 伤害倍率 |
|---|---:|
| 正交四格 | 80% ATK |
| 斜向四格 | 40% ATK |

伤害规则：
- 法术伤害。
- 允许暴击，按李自身暴击属性判定。
- 正常受到法术抗性减免。
- 护盾、伤害减免和伤害免疫按全局规则生效。
- 可以对 Boss 造成伤害。

可破坏物体受到相同距离倍率的伤害：
- 正交四格：80% ATK。
- 斜向四格：40% ATK。
- 可破坏物体不会获得引燃。

### 6.4 爆炸施加引燃

爆炸命中敌方单位：
- 立即施加1层引燃。
- 最大叠加2层。
- 已有2层时不增加层数，只刷新持续时间。
- 持续时间刷新为2个敌方阶段。

爆炸命中可破坏物体时不施加引燃。

### 6.5 连锁与结算规则

一次连锁从初始伤害产生的死亡事件开始，直到该批相关死亡余烬结算完成。

统一流程：
1. 完成产生死亡事件的当前伤害结算。
2. 记录该次结算中的所有死亡单位、死亡位置、死亡瞬间引燃状态与击杀来源。
3. 在第一个爆炸执行前，统一确定本次连锁的触发资格。
4. 按固定单位结算顺序逐个处理符合资格的死亡余烬。
5. 同一连锁中，同一目标最多承受一次死亡余烬爆炸伤害。
6. 同一目标被后续爆炸覆盖时，不重复造成伤害，但仍可刷新引燃持续时间。
7. 当前连锁中新施加的引燃不能成为当前连锁的新触发资格。
8. 爆炸伤害仍可正常触发其他引燃相关效果。
9. 死亡余烬可以在敌方阶段触发。

如果爆炸触发其他引燃相关效果并间接造成敌人死亡，仍按既定资格规则检查；不能把所有间接死亡一概排除。目标必须符合当前连锁开始前的引燃资格、死亡瞬间状态及允许的击杀来源。仅由当前连锁新施加的引燃，不得为目标补出本次连锁触发资格。

## 7. 技能02：黑雨

**类型：主动技能一**

### 7.1 技能定位

范围引燃铺设技能。主动伤害较低，主要价值是大范围给敌人施加双层引燃，为死亡余烬创造连锁条件。

### 7.2 基础规格

| 项目 | 规则 |
|---|---|
| AP消耗 | 1 AP |
| 施法距离 | 以李为中心，最大距离5格 |
| 距离算法 | 曼哈顿距离 |
| 施法方式 | 指定目标格 |
| 目标格 | 可为空地，也可选择李自身所在格 |
| 技能范围 | 半径2格菱形，共13格 |
| 主动伤害 | 20% ATK |
| 伤害类型 | 法术伤害 |
| 暴击 | 允许，按李自身暴击属性判定 |
| 引燃 | 范围内存活敌人达到2层 |
| 引燃持续时间 | 刷新为2个敌方阶段 |

### 7.3 视线与地形

- 李到指定目标格必须保持视线。
- 高墙阻挡施法视线。
- 技能范围从目标格向外传播，高墙遮挡其后方格子。
- 高墙遮挡逐格检查：检查中心到范围内目标格之间的直线路径；路径受高墙阻挡时，该格不受黑雨影响。
- 低矮障碍物不阻挡。
- 地图边缘可施放，超出地图部分忽略。

### 7.4 伤害目标与引燃

- 伤害范围内敌方单位和可破坏物体。
- 不伤害友方单位。
- 敌方单位受到20% ATK法术伤害。
- 可破坏物体受到20% ATK伤害，但不施加引燃。
- Boss 正常受到伤害并施加2层引燃。
- 护盾正常吸收伤害，但不阻止引燃。
- 伤害减免正常生效，引燃不受伤害减免影响。
- 伤害免疫不自动等于引燃免疫；只有明确免疫引燃或负面状态的单位才能抵抗引燃。
- 范围内存活敌方单位无论是否实际受到伤害，都立即获得引燃，除非其具有对应状态免疫。
- 没有引燃时直接施加2层；已有1层时补足至2层；已有2层时只刷新持续时间。
- 新获得的引燃从下一次敌方阶段结束时开始造成持续伤害。

### 7.5 特殊情况

- 没有敌人时仍然可以施放。
- 已死亡、已移除或正在离场的单位忽略。
- 目标确认后立即执行，不可取消。

## 8. 技能03：焚城指令

**类型：主动技能二**

### 8.1 技能定位

全场引爆技能。主动施放时，一次性引爆战场上所有符合条件的引燃敌人，不重新选择区域。

### 8.2 基础规格

| 项目 | 规则 |
|---|---|
| AP消耗 | 2 AP |
| 引爆资格 | 至少拥有1层引燃的敌方单位 |
| 直接伤害 | 100% ATK |
| 周围溅射 | 50% ATK |
| 爆炸范围 | 每个引爆目标周围3×3九宫格 |
| 伤害类型 | 法术伤害 |
| 暴击 | 允许，按李自身暴击属性判定 |
| 引燃处理 | 结算后清除直接引爆目标身上的全部引燃 |

### 8.3 引爆与结算

1. 施放瞬间统一记录所有拥有至少1层引燃的敌方单位。
2. 所有爆炸作为同一技能批次同时结算。
3. 被其他爆炸击杀的引爆目标，仍然会正常产生自己的爆炸。
4. 焚城指令直接伤害击杀符合死亡余烬资格的敌人，可以触发死亡余烬。
5. 完成全部焚城指令爆炸伤害后，统一记录死亡事件并处理死亡余烬。
6. 所有爆炸与死亡余烬相关结算结束后，清除直接引爆目标身上的全部引燃。
7. 死亡余烬爆炸造成的击杀不会继续触发新的死亡余烬。

### 8.4 重叠伤害上限

多重爆炸覆盖同一敌方单位时，伤害不得无限累加。

| 目标 | 本次技能伤害上限 |
|---|---:|
| 直接引爆目标 | 自身100% ATK + 最多一次50% ATK溅射 |
| 非引爆敌方单位 | 最多一次50% ATK溅射 |

- 直接引爆目标受到自身100% ATK伤害。
- 直接引爆目标最多额外承受一次50% ATK溅射伤害。
- 非引爆目标无论被多少爆炸覆盖，最多承受一次50% ATK溅射伤害。
- 更多爆炸覆盖不再增加敌方单位受到的溅射伤害。

**可破坏物体的边界：** 已确认可破坏物体每个爆炸造成50% ATK伤害，早期规则允许重叠累加。后续敌方单位伤害上限的确认未明确覆盖可破坏物体，因此本稿保留可破坏物体按每个爆炸分别结算、重叠可累加的原规则，不擅自将敌方单位上限套用到物体。该边界列为协作者审阅事项。

### 8.5 其他规则

- 不伤害友方单位。
- 高墙阻挡爆炸传播，低矮障碍物不阻挡。
- 可破坏物体受到每个爆炸50% ATK伤害。
- 爆炸不施加引燃。
- 正常受到法术抗性、护盾、伤害减免和伤害免疫规则影响。

## 9. 技能04：白昼终焉

**类型：终极技能**

### 9.1 技能定位

指定区域连续轰炸技能。一次施放连续完成四轮轰炸，最后一轮额外提高伤害。

### 9.2 基础规格

| 项目 | 规则 |
|---|---|
| AP消耗 | 2 AP |
| 终极能量 | 5点 |
| 施法距离 | 曼哈顿距离5格 |
| 施法方式 | 指定地图格 |
| 轰炸范围 | 中心格曼哈顿距离2格，共13格 |
| 轰炸次数 | 连续4轮 |
| 第一至第三轮 | 每轮45% ATK |
| 第四轮 | 85% ATK |
| 理论总伤害 | 220% ATK |
| 引燃 | 每轮对命中的存活敌人尝试施加1层 |

### 9.3 施法与区域规则

- 玩家指定一个地图格作为固定轰炸中心。
- 四轮轰炸使用相同中心与基础区域。
- 可以选择李自身所在格。
- 可以选择高墙所在格作为轰炸中心，但高墙仍阻挡其后方格子的范围传播。
- 李到轰炸中心必须保持视线。
- 高墙阻挡轰炸范围传播，低矮障碍物不阻挡。
- 地图边缘超出部分忽略。
- 四轮轰炸不重新选择中心，但每轮重新检查有效目标格。

### 9.4 施放与资源支付

- 确认施放后立即扣除2 AP和5点终极能量。
- 即使后续轰炸被其他效果中断，也不返还已支付资源。
- 施放后立即连续完成四轮轰炸。
- 每轮之间存在短暂结算间隔，但仍属于同一次施放。

### 9.5 每轮结算流程

每轮严格按以下顺序执行：

1. **检查战场：** 重新检查敌人位置、存活状态、高墙遮挡和有效轰炸范围。
2. **结算伤害：** 前三轮每轮45% ATK，第四轮85% ATK。
3. **记录死亡：** 统一记录本轮死亡单位、死亡瞬间引燃状态与击杀来源。
4. **处理引燃：** 对本轮伤害结算后仍存活的敌人施加或刷新引燃。
5. **处理死亡余烬：** 根据本轮记录的死亡事件，按固定单位结算顺序处理符合资格的死亡余烬。
6. **进入下一轮：** 上一轮所有相关结算完成后，重新检查下一轮战场状态。

### 9.6 伤害、引燃与存活规则

- 每轮独立造成伤害。
- 敌人死亡后不再受到后续轰炸。
- 每轮开始重新检查范围内敌人；进入区域的敌人也会受到后续轰炸。
- 每轮命中尝试增加1层引燃，最多2层。
- 已有2层时不增加层数，但刷新持续时间。
- 敌人免疫引燃但不免疫伤害时，正常受到伤害，不获得引燃。
- 第四轮先结算85% ATK伤害，再对存活敌人施加或刷新引燃。
- 每轮均伤害可破坏物体：前三轮每轮45% ATK，第四轮85% ATK。
- 正常受到法术抗性、护盾、伤害减免与伤害免疫规则影响。
- 白昼终焉击杀可以触发死亡余烬，遵循死亡余烬自身资格和连锁限制。

### 9.7 轮次间联动

- 每轮轰炸完成伤害与引燃处理后，处理该轮死亡余烬，再进入下一轮。
- 死亡余烬爆炸施加的引燃可以被白昼终焉后续轮次利用。
- 多个死亡余烬同时触发时，先记录全部死亡，再按固定单位结算顺序逐个处理。
- 同一连锁中，同一目标最多承受一次死亡余烬爆炸伤害；重复覆盖不重复造成伤害，但可以刷新引燃。
- 白昼终焉不同轰炸轮次属于不同结算阶段。前一轮死亡余烬施加的引燃，可以成为后一轮轰炸击杀目标时的引燃资格。
- 死亡余烬爆炸造成的击杀不会在同一连锁中继续递归触发新的死亡余烬。

## 10. 全技能联动与统一边界

### 10.1 典型战术循环

1. 使用黑焰射击或黑雨施加引燃。
2. 利用黑雨快速铺设多目标双层引燃。
3. 通过焚城指令引爆全场符合条件的敌人。
4. 利用死亡余烬将符合资格的死亡转化为范围爆炸与进一步引燃。
5. 在敌人密集或需要持续压制的区域使用白昼终焉。
6. 白昼终焉前一轮的死亡余烬可以为后续轰炸轮次创造新的引燃目标。

### 10.2 同一连锁与不同轮次的边界

必须区分：
- **同一连锁内部：** 新施加的引燃不能扩大当前连锁的触发资格；同一目标最多承受一次死亡余烬爆炸伤害。
- **不同轰炸轮次之间：** 上一轮已经完成的死亡余烬结算可以影响下一轮；上一轮新施加的引燃可以被下一轮利用。

### 10.3 友军与可破坏物体

- 李的所有范围技能均不伤害友方单位。
- 死亡余烬、黑雨、焚城指令和白昼终焉可以按各自规则伤害可破坏物体。
- 可破坏物体不获得引燃。
- 焚城指令可破坏物体的重叠伤害按第8.4节所列原规则处理，等待审阅确认。

### 10.4 地形

- 高墙阻挡的范围与方向以各技能自身规则为准。
- 低矮障碍物不阻挡李上述技能的视线或范围传播。
- 高墙对指定中心格本身的可受击性，除白昼终焉允许选择高墙格作为中心外，仍须按全局地形规则核对。
- 具体直线格线算法须与 ECHO 网格与视线系统统一，不由本角色文档自行创造另一套底层算法。
