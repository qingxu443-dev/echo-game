# 当前范围、旧规划对账与决策登记

核对日期：2026-11-27。源码基于 `7b919e2`，本轮战术集成修复随实施 PR 验证。本文落实 ECHO-001、002、003 的登记职责；登记完成不表示待决玩法已获裁决。原设计文档保留其历史口径，当前实现、验收和未决事项按下表区分。

## 当前交付范围与计数

技术栈为 Godot 4.7.2 Standard / GDScript / Resource `.tres` / Compatibility OpenGL，Windows 桌面原型，1280×720 逻辑视口通过 canvas_items 缩放。入口依次为主菜单、营地、教学遗迹或春之境。当前角色是瑟弗林与樱；正式角色成长、夏秋冬与终焉、Android 不属于已交付范围。

遭遇目录实际有 **20 个定义**：`SpringEncounterCatalog.ENCOUNTERS` 的 B001–B012、`ELITES` 的 E-B001–E-B005 和三个 Boss。三张模板各引用四场普通、一场精英和一场 Boss，即 **18 个主路线引用**。三模板合计覆盖全部十二场普通、E-B001/E-B003/E-B005 和三个 Boss。E-B002/E-B004 是目录中的额外精英，不是丢失的两个地点。事件伏击可复用目录，不另增主路线数量。验证来源为 `test_spring_encounters.gd`、`test_spring_map.gd`、`test_spring_content_flow.gd`。
